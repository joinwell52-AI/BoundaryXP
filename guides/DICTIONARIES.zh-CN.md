# L2 / L3 自定义字典

**[打开完整中文格式规范、目录示例和导入说明](../docs/mcp/npm/guides/DICTIONARIES.zh-CN.md)**

当前支持完整目录导入：L2 为 8 个 JSON＋README，L3 为 3 个 JSON＋README。页面按“选择层级 → 选择文件夹 → 校验 → 录入名称 → 保存”操作，校验通过后才能保存。MCP 可通过 `bx_dictionary_format`、`bx_dictionary_validate`、`bx_dictionary_import` 使用相同规范。

本入口兼容 npm README 的相对链接。已有任务与字典不会因打开文档而改变。
