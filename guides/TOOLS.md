# 21 个 MCP 工具 / 21 MCP tools

适用 `boundaryxp-mcp 0.4.0-rc.9`；当前完整清单、参数、两套分析模式及新增 L2/L3 字典工具见[工具说明](../docs/mcp/npm/guides/TOOLS.md)。本页是旧链接的兼容入口，不是旧版本工具清单。

For rc.9, read the [21-tool reference](../docs/mcp/npm/guides/TOOLS.md) for the complete inventory, parameters, host/API modes and custom L2/L3 workflow. This page preserves an old URL, not an old tool inventory.

也可直接调用 `bx_capabilities`，指定 `language:"zh-CN"` 或 `"en"`、`help_topic:"tools"`。查看单项时增加 `tool_name`。帮助与格式查询不发起分析或导入。

Use built-in bilingual help through `bx_capabilities` with `language`, `help_topic:"tools"` and optional `tool_name`. Help and format discovery do not analyze or import.
