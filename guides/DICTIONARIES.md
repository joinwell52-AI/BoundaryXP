# Custom L2 / L3 dictionaries

**[Open the complete English format specification, directory examples and import guide](../docs/mcp/npm/guides/DICTIONARIES.md)**

Full-directory imports use 8 JSON files plus README for L2, or 3 JSON files plus README for L3. In the workbench, select the layer and folder, validate, enter a name, then save. Validation must pass before saving. MCP exposes the same specification through `bx_dictionary_format`, `bx_dictionary_validate` and `bx_dictionary_import`.

This entry supports relative links rendered from the npm README. Reading it does not change existing tasks or dictionaries.
