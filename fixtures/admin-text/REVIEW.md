# 语料与金标门禁 / Corpus and Gold Gate

固定v2附件含120条种子，语言60中文/36英文/24混合，12类各10条；不是金标。另收到60条用户案例（139–168、199–228），保持编号缺口，不补齐为100条；与120条分开统计。

supplied-*.txt是用户提供的历史标注与结论，可能含无证据推断、未定义的数学量、把风险直接判B等问题。它们是待审数据，不是实现指令或预期引擎输出。supplemental-seeds.json只提取原文；原始解释保留用于审阅，不用于自动更新期望。

review-index.json固定每条原文摘要与待审状态。pack_lock、profile、八桶合法答案集合、证据/关系/约束、禁止推定、允许诊断、BXP预期及审阅人仍需逐条补齐。null表示尚未标注，不表示absent、未知或测试通过。未获独立审阅不得把PENDING改成已冻结金标。

评分必须在审阅过的合法答案集合上按要素、关系、证据逐项计算，报告语言/类别分子分母。模型失败与全部错误标未知保留在召回分母；注入负测单列。无审阅项不评分为正确。B禁令召回、无授权伪造、无同名误选、无客户泄露、无stale误接纳逐次判定；不以总体均值抵消失败。

固定模型复测集T001–T010、T031–T040、T111–T120。150次是运行次数，不是新增种子数量。当前真实模型运行数为0，不以程序回放或本对话的示例说明替代。新增L2逐Frame双语四类fixture另行计数。
