# BXP 0.3 修订与迁移 / Revision and Migration

状态 / Status: `DRAFT_FOR_REVIEW`\
协议 / Protocol: `0.3.0-draft.1`\
套件 / Suite: `1.0.0-draft.2`\
源码 / Source: `1.2.4-preview.1`

## 1. 范围 / Scope

本次仅修订协议、Schema、参考计算器、向量和必要文档。不改 7+1 核心、不设计 Logo、不扩展 L1/L2/L3 包、不改 ADMIN 本地 Python 路径，不接入模型。中英文规范同版本、同节编号维护；译本与英文冲突时仍以英文为准。

This revision changes the protocol, schemas, reference evaluator, vectors and related documentation only. It preserves the 7+1 core, approved branding, semantic-pack boundaries and local Python ADMIN path. English and Chinese documents share versions and section numbering; English remains normative.

## 3. 不兼容迁移 / Incompatible migration

旧草案协议 `0.2.0-draft.1`、套件 `1.0.0-draft.1` 保存在独立仓库 Git 提交 `1f514455774b1b4260c789f493c4e4bc3a167fa6`。旧代码和旧测试结果仅作为历史基线，不是本次验证。

The previous protocol and suite remain available at that immutable standalone-repository commit. Historical results are not new verification.

调用方必须 / Callers must:

1. 选择精确新版本的 Schema；不能只替换版本字符串。/ Select exact-version schemas, not merely relabel old inputs.
2. 将小数和不安全整数端点改成字符串，检查整数域及开闭端点。/ Encode fractional/large bounds as strings; review domains and endpoint inclusivity.
3. 补齐必需身份状态、修复多余字段、重复 ID 和原文偏移。/ Supply required identity states and repair extra fields, duplicate IDs and evidence offsets.
4. 核对状态切片；同域逻辑现合取；跨域全局约束必须显式带证据投影。/ Review scope identity, conjunction and explicit projection of applicable global constraints.
5. 多来源提供精确文本、版本和摘要；来源不是真实性或授权证明。/ Supply source text, versions and digests; these do not prove authority.
6. 消费者接收 input_digest、scope_id、domain、字符串端点和逻辑 constraint_ids。/ Update consumers for new result fields and decimal-string bounds.
7. 接受“已知冲突 + 未明确发现”并存，不能把 consistent 当成可执行。/ Preserve known conflict and unknown findings together; consistent does not authorize execution.

Schema 家族 URN 仍是 v1；必须按草案版本隔离校验器资产，不把两个不同草案的同名 URN 加入同一注册表。旧产品 API 未静默迁移。

Schema-family URNs remain v1; isolate schema registries by exact draft version. Existing product APIs are not silently migrated.

## 4. 向量审查 / Vector review

保留原 176 个用例 ID，其三个结果轴没有改变；174 条计算对象增加作用域／规范数值等字段，50 条发现更新证据去重、消息或上下文，全部增加新协议版本和完整输入摘要。新增 `BXP-C2001`—`BXP-C2032` 共32条，基础合计48条，历史计算模式派生160条，总计208条。

The original 176 case IDs retain their three evaluation axes. Typed calculations change in 174 cases and findings in 50; all receive the new version and input digest. Thirty-two hardening cases bring the suite to 208, with 48 foundational cases and 160 historical-pattern derivatives.

新用例的关键结论和数值由手写断言核对，再由参考实现产生完整候选结果。已逐类核对兼容性差异，不声称完成双人独立评审或第二实现互操作。新增双语测试验证的是**人工结构化投影的同等计算**，不是原文自动抽取准确率；抽取金标仍为0。

New cases have hand-authored verdict/value assertions checked before candidate generation. Full envelopes are still generated by the reference evaluator. This is not dual independent review, a second implementation, or extraction-quality certification. Bilingual tests compare manually structured projections; extraction gold remains zero.

## 6. 仍未完成 / Remaining boundaries

- Profile ID 不会自动加载策略；语义包版本摘要需生产者固定，本轮未开发包加载功能。/ Profile IDs do not auto-load policy; producers must pin pack/rule provenance.
- 作用域不等于可执行条件引擎，不做制度优先级、继承或跨作用域联合求解。/ Scopes do not execute guards, precedence, inheritance or cross-scope solving.
- 提交证据不证明归一化正确，也不证明全局禁令投影完整。/ Evidence does not prove normalization or global-policy projection correctness.
- 参考入口接收已解析 JSON；解码器必须拒绝重复键并保留数值精度，不能指望对象计算器恢复已丢失的数字。/ The object API cannot recover duplicate keys or rounded numbers; decoders must reject duplicates and preserve numeric precision.
- 参考线上消息固定英文，显示层可以中英文呈现；原文、机器码、数值和冻结信封不随展示翻译改变。/ Wire messages stay stable; localized displays must preserve evidence and wire semantics.
- 旧 CLI/MCP/HTTP 与 ADMIN 入口未统一到 BXP 0.3，尚无第二独立实现。/ Existing product adapters are not yet unified on BXP 0.3; no second independent implementation is claimed.
- 保持私有、Draft、空业务决定和空执行授权；不公开、不发布、不改许可证。/ Private draft only; null business decision and execution authorization, no release or relicensing.
