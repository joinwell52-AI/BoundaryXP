# BoundX Naming and Trademark Use Draft

状态：`DRAFT_FOR_REVIEW`。名称仍须完成专业检索；本文不声称任何地区已经注册商标或认证商标。

## 1. 统一命名

- 中文正式名称：界痕
- 英文品牌与协议前缀：BoundX
- 短命令：`bx`
- 模块前缀：`@boundx`
- 协议：BoundX Task Boundary Protocol（BXP）

不得把“界衡”“Boundx”“DTBP”作为平行产品或平行协议标识。

## 2. 描述性兼容声明

在正式认证计划建立前，第三方只能作带版本的事实性描述，例如：

```text
Implements BXP-IR and BXP-CALC for BXP-0001 0.2.0-draft.1.
```

不得使用 `BoundX Certified`、`Official BoundX`、`BoundX Approved` 或容易使用户误认为由 BoundX 维护者生产、担保或审核的表述。

## 3. 认证标识保留

未来若建立认证计划，必须另外定义测试机构、利益冲突隔离、版本、复测、申诉、撤销和标识使用期限。在该政策正式采用前，不签发认证徽章或公共认证名单。

## 4. Fork 与衍生实现

衍生实现可以说明其兼容的协议版本，但应使用自己的产品名称。对协议的兼容性不等于对 BoundX 产品名称、Logo、域名或企业服务的使用许可。
