# BoundX语义包

当前产品研究行业为软件开发与AI。

- L1：core-ontology@1.1.0，通用本体。
- L2：software-ai@0.2.0，行业动作、实体、角色、资源、引用、完成态与风险。
- L3：Enterprise L3 Profile v2目标契约，企业身份、组织、显式权限、委派、政策和时间作用域。
- L0为BXP协议与确定性Core，不是语义包。

软件与AI子类：swe-devsecops、ai-mlops、ai-rag-infer、agent-governance。

包引用需绑定版本和摘要。加载包不构成业务授权；角色和岗位不能推出权限；风险词条关联不能代替证据和确定性求值。

参见[语义上下文规范](../docs/SEMANTIC-PACK-SPEC.md)、[企业语义](../docs/L3-EMPLOYEE-DIRECTORY-GUIDE.md)及[开发任务书](../docs/tasks/BXP-PRODUCER-BENCHMARK-DEVELOPMENT-TASKBOOK-v1.2-LOCAL.md)。具体实现状态不以文件存在或模型下载成功推定。
