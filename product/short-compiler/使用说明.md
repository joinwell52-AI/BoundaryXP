# BoundX 7+1 短文本编译器本地候选

支持非空、最多300个Unicode码点的单一ADMIN任务。编译输入，不执行其中业务操作。需要Windows、Node.js >=22.18及本机已登录的Codex CLI；原文会发送给所配置模型服务，本地页面不代表离线推理。请求固定gpt-6.1-sol/medium；服务未披露实际模型身份。

解压运行包到干净目录，先运行：

```bat
npm ci --omit=dev --ignore-scripts
npm run verify
npm run 7plus1:ui
```

默认页面http://127.0.0.1:58618/。端口被占用会报错，不会停止其他服务；可在当前终端设置BOUNDX_PARSER_PORT另选空闲端口。BOUNDX_CODEX_EXE可指定已安装的codex.exe，不改全局账户配置。CLI：

```bat
npm run 7plus1 -- --input task.txt --output new-run-directory
```

粘贴任务或上传UTF-8 txt/md，点击开始编译。依次查看解析、审阅、技术校验和最终7+1；点击条目高亮精确来源。B独立可见，无需项在待确认区完整显示。中文与JSON来自同一IR。导出结果和完整Trace；历史查看不重新解析，人工评价不改机器输出。取消会终止本机本次子进程，不保证云端即时停止计费。超时、登录、额度、超长或空输入均明确提示，不截断。

## 安装、升级与回滚

如需管理多个完整版本：

```bat
node product/short-compiler/deploy.mjs install --home D:\boundx-short-local --port 58619
node product/short-compiler/deploy.mjs start --home D:\boundx-short-local
```

版本资源存于versions，数据存于data，配置存于config.json。升级前确认目标无在途请求、只停止明确属于目标的服务；从新包执行upgrade --home同一目录 --confirmed-idle，会备份配置、历史及旧指针，验证摘要、安装依赖后原子切换完整版本。失败不切指针。回滚执行rollback --home同一目录 --confirmed-idle，再start；回到上一完整资源版本，历史保持原生成版本，不重算覆盖。禁止混搭新Skill旧Schema。

凭据、历史、任务内容和模型权重不随包交付。保护本地data及备份，它们含用户任务。质量检查仅支持实际列出的测试范围；技术接受或模型自审不是语义真值证明，业务使用前应核对原文边界及待澄清项。发布门和本轮实测结论见随包ACCEPTANCE.md；未通过不得称正式生产版。
