# BoundX短文本7+1编译器：031-R1候选

支持非空、最多300个Unicode码点的单一ADMIN任务；原文仅用于编译，不执行其中的业务操作。Windows、Node>=22.18、已登录且有额度的Codex CLI是运行前提。原文发送给配置的模型服务，本地UI不是离线推理。固定请求gpt-6.1-sol/medium，服务实际模型身份未披露。

解压完整运行包到干净目录，使用现有安装模块：
```bat
node product/short-compiler/deploy.mjs install --home D:\boundx-short-local --port 58619
node product/short-compiler/deploy.mjs start --home D:\boundx-short-local
```
端口被占用不会停止其他服务。选择空闲端口；原58618恢复有独立策略阻塞，本包不是绕过该阻塞的工具。核心、两个Skill、合同、Schema、UI和渲染全部来自完整versions版本。可在其他工作目录使用上面脚本的绝对路径启动；资源被破坏在模型前拒绝，绝不回退开发工作区。

一次CLI：在包根执行npm ci --omit=dev --ignore-scripts及npm run verify，然后：
```bat
npm run 7plus1 -- --input task.txt --output new-run-directory
```
输出目录不得覆盖。BOUNDX_CODEX_EXE可指定既有codex.exe，不修改全局账号配置。

页面粘贴或上传UTF-8 txt/md后开始编译，查看I/O/A/P/R/V/C/B、原文证据、未决和独立B。生成结果RESULT与交付DELIVERABLE的模态分别保留；无需并非禁止。产物关联只表示同身份用途；产物可用性依赖注明本次结果及所使用部分/完整结果，不自动要求整项生成结束。明确时序另见TEMPORAL，实际状态保持UNKNOWN。中文、JSON、CLI与页面使用同一IR；点击条目显示精确来源。

导出最终JSON、中文或完整Trace；历史按生成版本只读，不重新调用模型。刷新与重复点击不重复提交。取消只保证终止本机本次子进程，不保证云端即时停止计费。登录、额度、超时、技术合同问题分别提示；0长度/超长输入不截断。

升级前核对目标版本/PID、备份并确认无在途请求；仅停止明确属于该目标且获正常许可的实例。从新包执行：
```bat
node product/short-compiler/deploy.mjs upgrade --home D:\boundx-short-local --confirmed-idle
node product/short-compiler/deploy.mjs start --home D:\boundx-short-local
```
安装完整版本及锁定依赖成功后原子切换指针。升级不会覆盖历史。失败保留旧指针，修好后可重新安装新版本；回滚：
```bat
node product/short-compiler/deploy.mjs rollback --home D:\boundx-short-local --confirmed-idle
node product/short-compiler/deploy.mjs start --home D:\boundx-short-local
```
回滚完整旧版本，不把新Skill混到旧核心。备份包含配置、指针和实际data_dir，可由用户恢复；历史不重算。
