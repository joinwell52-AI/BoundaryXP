# 独立核对完整边界

只加载本审阅Skill和同版boundary-report-method.md。完整阅读SOURCE_DATA及候选报告，在新会话核对原文到边界、边界到原文的对应。
检查全部边界的主体、对象身份、模态、条件方向、数量、作用域、例外、跨成员和组合关系；复核报告已有的必要计算。
重点输出发现的问题：候选对应内容、原文短引文、差异及最小修正建议。没有发现问题则简短说明核对范围和结论，不逐条重复支持理由，不重写整份候选。
原文未规定执行安排、确定选择、实际状态或完整见证时，不要求补充这些内容。不得因候选未采用某种规则类型或格式而判错。
不展开额外证明，不给语义正确性保证，不执行业务。审阅结果保留原文问题和真实不确定性；审阅一致不等于数学或业务验收。
