## 1. 验证的第一目标

**核对ADMIN原文是否被完整、正确地表达为7+1。** 合法JSON、来源引文匹配、审阅SUPPORT、程序无异常、Proof可达或SEAL通过，都不是自然语言准确率。

测试结束可以得到失败或待审结论。软件可启动、测试完成、候选交付、产品质量门通过和公开发布是不同状态。

## 2. 必须分别记录的层次

| 层次 | 核对内容 |
|---|---|
| 原文与预期 | 原文字节、允许上下文、逐事实预期、等价形式及争议；预期先于本轮输出冻结 |
| 首次候选 | 事件、身份、角色、模态、条件、范围、数量、指代是否完整；有无多造事实 |
| 内部修订后候选 | 正常产品有界修订是否纠正问题；不能将其冒充首次就正确 |
| 程序消费与IR | 正确候选是否被损坏；错误候选是否被接受；拒绝后是否仍保留覆盖缺口 |
| 最终JSON | 各视图及关联、来源、未指定和真实竞争是否完整可消费 |
| 中文与界面 | 与同一IR一致；对象、角色、状态所指事件、全称与条件不能被显示丢失 |
| 可计算结构 | 用显式模拟观测检查类型、范围成员、条件方向、数量目标、未知与依赖；不冒充真实业务观测 |
| 使用与部署 | 同版CLI/UI、安装、版本隔离、历史、导出、取消、升级和回滚 |

正确保留真实歧义可以是符合预期；将清楚的语义全部设未决不算成功。错误重复一致不是稳定正确。域不同、必要条件不同或对象不同不能当成ID差异忽略。

## 3. 数据、评测与模型隔离

每次产品运行只接收本案原文和获准资源。测试ID、标准答案、案例分类、根因报告、其他任务和Gold说明文档不得进入被测解析/审阅请求或可读目录。

人工Source复核、执行Codex的审阅、模型自审与机器比较器分别注明。LLM自审不是独立人工Gold；审定者必须能回到原文、主张和具体关系。

比较器允许语义等价的ID、同义标签和结构表达，但不能只断言几个关键字存在。检查额外输出，尤其是没有来源的义务/许可、丢失禁止、条件方向改变、身份错绑与范围缩放。

若预期存在真实歧义，保留可确定部分并记录待审，不挑模型某次输出补成预期。后发现比较器错误时，在同一原始输出上另存重评分及理由，不覆盖首次成绩，不把标注变化算模型提高。

## 4. 回放、模型调用与版本

运行清单记录核心、两个Skill、有效bundle、共享合同、Schema、Provider、模型配置、安装包和依赖版本。实际服务模型身份未披露时不编造。

纯消费者或显示修复优先使用相同冻结响应诊断，报告`real_calls=0`及来源摘要。Skill、Schema、有效提示或模型可见合同变化时，旧响应不能验证新方法；也不能关闭摘要检查绕过不匹配。

开发分支根工作区CLI与固定58618安装UI可能不同版本。它们不能因为共享同一源代码谱系就被当作同版。核对时从相同完整安装版本调用；新旧样本分母与有效输出来源逐条说明。

真实请求、外层进程启动、内部重试信号、完整编译次数和不同原文数量分别统计。内部重试信号不是服务器实际收件或计费证明。模型用量预算以有效任务授权为准，文档不重置计数或追加额度。

## 6. 纯程序正反验证重点

来源无效、引用丢失、版本混用、重复ID、签名错误和必需依赖循环必须有反例。产物可用性不冒充事件强顺序，局部疑点不污染独立事实；必要前提不变充分许可。

范围验证须区分具体对象、有限枚举、类别域、全称与例外。同域不同成员、域外对象、未知或冲突成员归属都要检查；“未命中本条禁止”不等于授权。布尔ALL与类别FORALL不能混用。程序不得从原文或note关键词补量词及域。

数值需检查单位、目标、计数范围、比较符与未知值。中文需检查NOT_REQUIRED的主体/对象，以及同名状态所指不同事件。JSON与中文同源不能只由视觉上相似判定。

## 7. Gold与历史数据

原Gold-60以完整TASK为来源；Gold的人读说明、JSON审定事实与模型输入必须分离。机械文件核验、Source SHA匹配和符号模型回放不能直接当自然语言抽取成绩或Core重新计算。

原Core/L3研究计划、旧200/350等材料、旧三路线指标属于各自历史授权，不自动成为当前产品验证任务或预算。当前的53固定样本、指定重复及N组同样必须绑定实际版本；看过答案后修复的案例属于回归，不再称未见样本。

## 8. 产品质量门

同一版本应同时满足：声明范围内的完整语义验证、明确的未知处理、无已确认未关闭的关键错绑定/禁令/条件/范围缺陷、程序保真、真实UI/CLI使用、干净安装、升级回滚和数据保护。

Q05尚有域解释与新版补测问题，不能因为全量0失败、包可解压或量词出现就标产品READY。新报告应先给实际可用版本和能力，再给逐层结果、未运行和待审项。固定入口维护与语义研发分别报状态。
