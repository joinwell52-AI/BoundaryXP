# 界痕可视化使用指南

**源码 1.2.1-preview.1 的新流程见 [自然语言建议与双语操作指南](UI-ADVICE.md)**：连接测试变绿 → ADMIN 建议 → PM 自动分工与计算。下面保留已下载 1.2.0 便携包的操作说明。

适用版本：1.2.0-preview.1。一个本地页面完成任务整理、基线确认、PM 规划检查、提醒与记录。无需编写 JSON，也不需要安装 CodeFlowMu。

## 打开

Windows 便携包解压后，双击 **start-ui.cmd**。它启动本机服务并打开浏览器。请保留启动窗口；关闭窗口会停止服务。若浏览器没有自动打开，复制启动窗口中的 `http://127.0.0.1:端口` 地址。

源码环境在本目录运行 `npm run ui`，需要 Node.js 22.18 及以上；便携包内置运行时。不要双击 `ui/index.html`，它需要本地服务。

## 先体验，不用密钥

1. 点击“载入巡检示例”。这是固定人工映射，页面会明确标注。
2. 核对七张边界卡片。未明确的资源和版本可以保留为空。
3. 勾选核对，点击“保存为比较基线”。
4. 到第二步粘贴规划，选择“手动整理”，填写原句与完成条件；也可以配置模型帮助整理。
5. 核对后计算差异。第三步显示原句、依据、建议和可展开的数学反例。

“手动整理”不自动猜测语义。边界卡片和引用必须由你填写；普通用户的自动文本入口需要模型服务。

## 连接模型

点击右上角“模型设置”，填写：API 协议、**完整请求地址**、模型 ID、密钥。支持 Responses 与 Chat Completions 兼容协议。地址应含 `/responses` 或 `/chat/completions` 等实际端点，不只是网站首页。

豆包 Ark 可使用已开通的模型对应 Responses 地址。若服务支持 `thinking` 参数，可以勾选“关闭深度思考”；不支持该参数的服务不要勾选。本轮真实验证使用 `doubao-seed-2-0-pro-260215`，Chat Completions 路径有本地协议测试，未做每家供应商的真实兼容认证。

密钥仅保留在当前页面内存。刷新后需要重新输入，不写入任务文件、浏览器本地存储或服务日志。界痕不读取项目 `.env`，不自带共享密钥，也不把聊天订阅当作 API 额度。

只有点击“用模型整理边界”“让模型生成 PM 规划”“用模型整理规划”或“让 PM 复核并回复”才发起模型调用。一次完整初始流程通常是三次调用；复核及再次提取会增加调用。每次最多输出 6000 tokens，3 分钟超时，无自动重试。费用以供应商账单为准，点击取消不能保证供应商未处理或不计费。

## 你输入一段话后发生什么

模型先选择原句编号，程序再从原文取回引用。程序验证编号、范围和结构；用户核对其语义。若模型为某参数选择多段原句，界面展示覆盖它们的连续原文，**可能包含中间未选文字**，会显示专门提示，不能当作精确语义提取。

七参数不是必填评分表。原文没有的要求不会自动补进来。要增加要求，请编辑任务原文、重新整理并确认；确认只表示当前用户选择此版本作为比较基线，不验证组织身份或生成 ADMIN 授权。

## 测试 PM

保存基线后，可以直接让所配置模型扮演 PM，生成分工、依赖、验收和根收口条件。模型只输出拟议文本，没有工具权限，不会派出真实任务。切换模型设置可以测试另一个模型；调用记录保留返回模型与 usage。

当前“生成 PM 规划”试测预设 DEV、QA、OPS 执行角色，EVAL 由 ADMIN 独立安排，适用于本项目研发巡检案例。粘贴其他团队的已有规划进行检查没有这个角色预设；不要把预设 PM 测试器误认为适用于所有团队的自动组织器。

生成后点击“用模型整理规划”，核对七参数、动作和条件。总规划包含 PM 自己的汇总职责，子任务单独计数；不强制拆成三个任务。条件含义相同时应沿用基线名称，不同名称或措辞产生的观察仍需核查。

点击计算后，主要变化优先展示，映射缺口折叠保存。可以复制提醒，也可以编辑提醒后请求 PM 复核。复核答复回到第二步，必须重新整理、核对和计算；“模型已经回复”不能标成问题已解决。

连续计算会同时对照原基线和上一版规划。上一版对照的观察总数不是“新错误数”，其中也可能包含文字变化、角色分工和映射缺口。

## 保存和接班

“保存记录”下载 JSON 数据文件，用户不需要编辑它；“导出报告”生成可读 Markdown。记录包含原文、候选映射、确认基线、规划、计算、回应与模型答复，不包含模型配置或密钥。

页面不自动持久保存。关闭前下载记录，下次用“打开记录”恢复。打开时重新验证已保存的计算；未完成草案仍可以恢复编辑，但不能冒充确认后的边界。旧比较结果属于对应旧基线，更换基线不会把旧结果变成新结果。

## 计算范围

本页接入七参数缺口、动作差异、总完成条件变化、未知依赖、有向环和逐项回应检查。**尚未将有限布尔分解契约编辑器接入图形界面**；该功能继续通过 CLI/MCP 使用。当前 UI 不证明子任务组合足以完成所有原要求，也不判断实际运行成功。

引用校验失败、模型输出格式错误、超时都会明确报错，不显示为“零异常”。语义提取仍可能错误，普通动作分工也可能触发差异观察。需要人核查，不作业务裁决。
