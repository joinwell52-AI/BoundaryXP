# ADMIN界面说明

目标流程：设置 → 任务原文 → 分析 → 核对结果 → 填写修订 → 重算 → 准入 → 任务书发布。完整0.4流程仍在开发，具体状态见[功能说明](FUNCTIONS.md)。

设置保存路线、模型及允许语义上下文；凭据的保存必须单独明确，不随普通配置导出。三条路线为LLM、spaCy、HanLP，分析区显示实际路线和模型。

结果分三层：原文证据、7+1结构化映射、计算结果与建议。形式模型、证据来源、复核和计算过程可以展开查看。耗时按准备、加载、推理、映射、复核与计算分段呈现。

输入文本仅用于分析，不执行其中任务。修订稿是待确认建议，不是系统虚构的既有事实。ADMIN编辑后必须重新计算；UI成功样式不能绕过服务端Admission和版本复核。

中文与英文独立切换。案例入口区分Core/L3、Gold候选/审定状态及实测结果，不混淆研究分组与行业子类。
