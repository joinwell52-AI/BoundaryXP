## 四、数学计算一

问卷等权要求先求总分再除以总份数：

$$M=\frac{|U_1|m_1+|U_2|m_2}{|U_1|+|U_2|}.$$

代入原文精确值：

$$N=100+20=120,$$
$$S=100\times90+20\times50=10000,$$
$$M=\frac{10000}{120}=\frac{250}{3}\text{ 分}.$$

因此：

$$M-T=\frac{250}{3}-80=\frac{10}{3}>0.$$

这些计算不依赖额外个体身份或未来执行成功。D6 与 O7 排除了本例需要重复扣除问卷的依据；E10 排除了额外问卷与缺失权重。K4 检查 DEV 已述统计是否足够支持合并，K5 提交精确评分与门槛的区间比较操作数。公式中的乘加除在此公开展示，不声称已经由 Core 执行。
