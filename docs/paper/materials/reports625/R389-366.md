## 三、形式模型

令 $d$ 为 DEV 的计算设备，$s$ 为 OPS 的采集设备，二者是本轮内稳定且不同的物理对象（E14、E23、E24）。令 $P_i$ 表示设备恒定功率，$t_i$ 表示计划运行时长，$e_i=P_it_i$ 表示计划电能。共同作用域只含本轮这两台设备，额度为 $L=2.2\,\mathrm{kWh}$（E6、E7）。

给定 $P_d=1.5\,\mathrm{kW}$、$t_d=40\,\mathrm{min}$，$P_s=500\,\mathrm W$、$t_s=2\,\mathrm h$。DEV 窗口包含加载、运算和落盘；两台设备各自在给定运行后关机，关机按零功率（E7、E14、E16、E23）。没有抵扣，也没有遗漏的额外待机分量。

共同能耗条件为 $e_d+e_s\le L$。设备身份与功率、时长保持联合绑定，不把 OPS 的时长套到 DEV 的功率上。相对启动时刻只影响瞬时功率函数，不改变给定两段运行的电能之和。

## 四、数学计算一

先统一单位，再计算同对象的功率与时长：

$$e_d=P_dt_d=1.5\times\frac{40}{60}=1\,\mathrm{kWh}.$$

$$e_s=P_st_s=\frac{500}{1000}\times2=1\,\mathrm{kWh}.$$

因此：

$$e_{\mathrm{total}}=e_d+e_s=2\,\mathrm{kWh}\le2.2\,\mathrm{kWh},\qquad L-e_{\mathrm{total}}=0.2\,\mathrm{kWh}.$$

组合资源查询 K5 保存两个独立分配身份，每项固定计划电能为 1 kWh，采用加法。其来源分别为 E14 与 E23；独立设备与不抵扣、汇总依据为 E24、E7、E25。该数值只比较当前计划，不代表实际电表读数。运行是否重叠不改变本式。
