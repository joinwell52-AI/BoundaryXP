## 三、形式模型

作用域 $\Sigma$ 固定为 MT004 本轮候选版本演练及其任务树。版本实体为 $r=\mathrm{rc12}$，目标环境为 $e=\mathrm{staging}$，受保护环境为 $p=\mathrm{production}$，可写目录为本轮 evidence。关系保留为“DEV 提供本轮 rc12 并声明 h12”“OPS 对本轮交接对象报告实测 h13”“OPS 计划继续向 staging 部署”，不只比较孤立环境标签。

词典实际命中：software-ai@0.2.0 的 /entities/21 将 staging、production 列为运行环境别名；/frames/18 将服务部署描述为作用于服务、环境、版本的 CHANGE 动作。部署查询同时返回模型部署等候选，本例没有模型对象，故采用服务发布部署含义；production 查询中的模型生产投放风险也不用于本例。生产禁令来自 E7，词典风险标签不产生授权或额外禁止。tenant-a@0.2.0 对“栖云协作台”的查询 total=0，不据此补企业对象映射或未知身份。

令 $h_d=\mathrm{h12}$ 为 DEV 声明值，$h_o=\mathrm{h13}$ 为 OPS 实测报告值。令 $m$ 表示本轮校验差异已被发现；E20、E30 的不同值及 E35 的明示差异支持 $m=1$。令 $c$ 表示 OPS 的拟议安排在该差异下仍先继续部署，E31—E32 支持 $c=1$。父限制的必要部分为 $m\Rightarrow\neg c$，完整条款还要求保留失败记录。

其他角色用其新增指令集合检查具体不干涉项：是否要求越出本轮环境／版本／写入范围、修改 production、改派角色职责、代审批、补造事实、取消停止或留记录要求。这里的 false 只表示完整任务书没有提出对应新增要求，不表示证明现实中从未发生该行为。已述测量事件记为 evt_ops_checksum，QA 记录事件记为 evt_qa_record；二者都不是部署动作，不将其套入“停止部署”的已发生动作查询。

## 五、数学计算二

父停止边界与 OPS 具体安排的比较为：

$$P=m\Rightarrow\neg c,\qquad S=m\land c.$$

代入 $m=1,c=1$：

$$P=1\Rightarrow0=0,\qquad S=1.$$

所以 $S\not\Rightarrow P$，其违反见证正是“发现本轮校验差异，仍先继续部署”。K3 同时检查其余新增要求：没有提出改 production、改派其他岗位、代审批或丢弃记录；这些局部保持不能消除停止边界的确定冲突。也不将“事后补核对”解释为已经修复差异或已经获准继续。

DEV 的具体工作是准备工件和交接清单并提供 rc12；DEV 文档整理员限定为已交材料、保持原始版本数值并写允许目录；QA 记录差异并暂不签发；QA 证据复核员保留原文关系、沿用 QA 安排且不自行批准。K1、K2、K4、K5 分别比较这些具体选择与适用父限制，未出现对应的禁止新增要求。它们没有被当作已完成部署，也没有被要求承担 PM 自有报告工作。

PM 汇总与向 ADMIN 报告的职责由 K7 单独检查全部五个后代是否提出改派、取消或覆盖；五项均未提出。DEV 自有准备职责和 QA 自有复核、汇报职责，分别在其下级 K2、K5 中检查责任非干涉。

## 六、关键区别与可满足性

规则保持与方案符合分开：OPS 的一般记录规则、staging 目标和 production 禁令可以继续保持，但具体“先继续、事后补核对”仍违反停止规则。其他角色没有新增受禁部署要求，故其任务书未越界；不能把 OPS 的方案冲突分摊给所有提供材料或记录差异的角色。

文本已述条件与行为归责分开：校验差异是当前记录已经支持的结果；QA 的 READINESS 不通过描述这一条件，不意味着 QA 制造差异或进行了部署。DEV 提供工件、OPS 测量和 QA 记录，均保留为已述事实；测量和记录本身不属于 E9 要求停止的动作。因此没有为相邻准备行为虚构 OCCURRED_ACTION 触发未知。

反例检查：若仅将 OPS 的计划改成发现差异后停止部署并保留失败记录，则在仍有 $m=1$ 的情况下令 $c=0$，有 $1\Rightarrow1=1$；所以父边界并非自身矛盾。若只保留 $c=1$ 而假设 $m=0$，虽能使蕴含成立，却与本例已有校验差异记录不符，不能作为本例通过补全。实际部署未发生也不改变拟议要求的冲突。

没有把通用“待确认项”措辞补成具体未知。也没有要求整理员现在证明部署成功、业务批准存在、生产零故障或覆盖未来所有运行时间。parent 的条件许可、角色交接和完成停止分别保留，没有把交接关系转换为额外执行先后依赖。

各子任务规则边界：DEV 未越界；DEV 文档整理员未越界；OPS 越界，违反发现校验差异后的停止要求；QA 未越界；QA 证据复核员未越界。

综合结论：越界，确定见证来自 OPS 的具体部署安排。其他角色的可靠局部结果保留，当前校验条件不满足也单独展示。
