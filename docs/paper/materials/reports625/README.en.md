# Original saved analysis reports: 625 cases

Each Markdown file is the exact UTF-8 string in report_markdown in the corresponding frozen result JSON. INDEX.csv binds its case ID, report digest, result path, and result digest. No new translation, semantic analysis, annotation change, or product run was performed. Original task language is retained; Chinese reports are not presented as English-language cases.

The JSON source remains authoritative for complete 7+1 carrier entries, shared relations, evidence, calculations, unknowns, diagnostics, and answers. A report is an access copy, not proof that every source mapping is correct. Existing display/control-character defects are retained and counted in the index, rather than silently changing evidence.

The package is research evidence for author/reviewer inspection. Data access and public redistribution must follow the availability and rights statement for the eventual record.
