# Frozen 625-case experimental evidence

This directory retains 625 original projects, 625 full saved results and the original STATISTICS-VERIFIED.json. Repeated tests are not counted as new cases. The 3,219 nodes and 3,469 calculation items retain their original identities, annotations, proposals, operands, findings and diagnostics.

Run `python -B evidence-r18/verify.py` to verify raw bytes and the original statistical audit. This does not call the workbench, execute product code or regenerate language-model outputs. Original live-workbench collection scripts are not distributed in this research-only package.

For independent annotation/LLM reconstruction and a retained aggregate audit, see [the provenance guide](../evidence-r22/README.md). For classification and mathematical witnesses, see [analysis625](../analysis625/README.md). The [report index](../reports625/INDEX.csv) exposes the original report strings without replacing their saved JSON records.

625/625 is case-level agreement in the retained compilation; individual differences, incomplete calculations and reference errors remain recorded. It is not independent blinded semantic accuracy.
