# 625组用例：分类、分析与数学复核

分析日期2026-11-06；测试快照日期2026-11-05。对象为625个当前项目、3219个任务节点和3469项提交查询。

- [逐组分类CSV](cases.csv)：625行，可按主类、算子、比较对象及答案筛选。
- [完整分类与查询索引](classification.json)：625组记录、3469项查询、未知条目及精确来源分组。
- [分析报告](REPORT.zh-CN.md)：方法类型、关联、未知、差异及适用范围。
- [分类程序](analyze.py)：运行`python -B analysis625/analyze.py`重算并与冻结分类比较。
- [可检查的Notebook](analysis.ipynb)：用Python 3查看分类、关联及六项数学复核，不依赖额外分析库。
- [六项数学复核](witness_checks.py)及[结果](witness-checks.json)：运行`python -B analysis625/witness_checks.py`复算。

原始数据位于[evidence-r18](../evidence-r18/README.md)。分类从保存的操作数和明确字段得出，不调用模型、不连接58618、不改Gold或源结果。数学主类对625组互斥；算子及目标涉及组数允许交叉。视图字段反映提交的表示，不自动证明自然语言覆盖或归属正确。

精确原文与父关系分组用于说明测试记录的来源重复，不等于任务语义去重，也没有把625组总数改成518。CSV和JSON均保存逐例到原文件的路径及摘要，便于人工复核。
