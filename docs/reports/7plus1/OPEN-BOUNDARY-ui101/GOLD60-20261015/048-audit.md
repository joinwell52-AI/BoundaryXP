发现两处将要求差异误判为冲突的问题：

1. **失败退出规则：无依据地推定冲突。**
   - 候选：R 节称“适用级别冲突”，末节第 2 项称“失败退出范围未统一”。
   - 原文：“任何一项不通过立即 `exit 1`”；“CI 模式（任何 P0 不通过 exit 1）”。
   - 差异：后一句未说“仅 P0”，不排除 P1 失败也退出，因此不能据此认定两句冲突，也不能削弱前一句明确规定的退出义务。
   - 最小修正：删除“级别冲突”的判断；保留 §G 六条扫描的任何一项失败立即退出，以及 CI 中 P0 失败退出的要求。对其他检查及 drift 的退出策略，仅标明原文未明确的具体范围。

2. **drift 验收：上限与更严格要求可以同时满足。**
   - 候选：末节第 3 项称，同一状态下“允许保留 P1 与 CI 零发现有冲突”。
   - 原文：“至多 P1 警告……无 P0”；“CI 日志可见……drift = 0”。
   - 差异：“至多 P1”允许零发现，并不要求存在 P1。即使针对同一状态，零发现也可同时满足两条；单项验收允许 P1，不代表整体验收允许保留 P1。
   - 最小修正：保留两处验收要求及 `drift = 0` 计数口径未定义的问题，删除冲突判断。
