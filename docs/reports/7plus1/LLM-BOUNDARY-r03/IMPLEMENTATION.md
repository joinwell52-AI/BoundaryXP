1. 有限事件证据可显式给出`template_id`与整数`index`，经既有`preparePlan`统一实例身份；状态证据通过`bindings`绑定局部实例变量。类型、定义域、时间和重复身份均校验，不从原文或备注猜测实例。

3. 解析输出共用`evidence_contexts`，计算项和联合见证通过显式ID引用，程序无损展开。缺失或重复ID报具体问题，不合成证据。
4. 移除重复的要求备注和分项叙述步骤；保留来源、类型、公式、操作数、结果、联合证明和缺口。
5. 审阅复用候选来源表，可分组列出已实际核对的目标。程序仅展开明列的目标；未列目标仍是审阅缺口。序列字段仍须单独审阅，异常项逐项保存。
