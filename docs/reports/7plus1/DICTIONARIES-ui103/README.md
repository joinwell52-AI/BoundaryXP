# ui103：补齐已有行业字典

ui102 的目录只注册软件与 AI 行业，遗漏本仓库已有的另外 11 个 L2 包。本次补齐汽车租赁、跨境关务、客服退款、金融信贷、车队物流、政务公文、医疗处方、系统运维、采购招投标、物业安全、仓储库存，共 12 个行业选项；保留“不使用”及原有三个 L3 测试包。

新增包原样来自 D:/boundx/domain-packs/l2，各包七个资源的字节数及 SHA-256 均与其原有 datapackage.json 一致。软件包沿用 0.2.0，其他包沿用 1.0.0，未修改词条或授权语义。包内历史 origin 占位信息不视为独立语义审定证据。

默认不选择字典；选择后只发送目录身份，模型按需查询选中包。生成和独立审阅绑定同一份快照；未选择的行业不能查询。术语定义不构成 ADMIN 授权。本轮不调用被测模型。

## 验证

12 项无模型测试通过：包含全部行业的目录覆盖、逐包可查询、跨包隔离、真实 stdio MCP 查询、生成与审阅同快照、HTTP 选择绑定和原快速报告回归。测试日志见 UNIT-TESTS.txt。安装包验证与实际部署证据另存，不把无模型测试称为真实语义验收。
