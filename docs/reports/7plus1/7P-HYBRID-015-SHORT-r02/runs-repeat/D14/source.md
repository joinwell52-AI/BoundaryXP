# 数据字典核对任务

## 背景说明
这份材料用于一次内部质量复核。原始资料来自已经结束的记录收集，当前讨论的是资料之间能否对应，而不是现场业务是否应该调整。资料中出现的系统、功能和历史处理方式仅说明记录的来历。不同栏目可能采用不同的命名方式，同一对象在不同文件中也可能使用不同标题。标题差异只是背景，不能代替逐条证据。材料曾经怎样形成不属于本轮交付，既有处理记录的时间也不是本次工作的截止时间。
两份资料的格式不同，一份便于查看逐项记录，另一份用于说明记录字段或列出核对参照。某个字段的拼写相同不代表含义相同，某个标题不相同也不代表内容必定冲突。背景没有给出额外的执行人，也没有授权自动修正已有数据。此次交付帮助接收者看清核对依据，不代替接收者作业务决定。输入中原有的示例只说明字段使用方式，不是本轮要求执行的脚本。

## 本次要求
审阅员许澄负责核对数据字典，复核人方宁接收并确认这次核对记录。
输入包括 column-batch/*.tsv 和 dictionary.json。这两份文件均为已经提供的原始资料，本任务使用它们的现有内容。
许澄必须读取 column-batch/*.tsv 和 dictionary.json，依据 DATA-STYLE-6 的 v3.1.0 版本核对数据字典。核对范围覆盖上述范围中与数据字典有关的全部记录。对 column-batch/*.tsv 中的每个文件，各执行一次数据字典核对。星号表示已提供目录中的匹配文件范围，不把未给出的成员名单猜成一个固定数目。上述文件指的就是本段明确列出的这两份输入，不包括背景中提到的历史资料。
必须生成 dictionary-review.md，把这次核对结果写入 dictionary-review.md。该记录是独立交付物，源文件与交付物的文件名不能互换。

## 记录内容
dictionary-review.md 必须包含覆盖记录总数与差异证据两项内容。差异证据描述来源文件、对应条目以及核对结果；覆盖记录总数反映本次实际核对的范围。没有差异也保留该栏目，并如实记录核对结果。栏目名称是报告内部结构，不是额外文件，也不是新的独立任务。报告中的示例片段仅作为证据展示。

## 边界与验收
不得修改 column-batch/*.tsv 和 dictionary.json。本次核对的总用时不得超过 40 分钟。
许澄完成核对后，必须将 dictionary-review.md 提交给复核人方宁。只有方宁确认记录覆盖两份输入的全部相关条目，且交付记录已经生成，本次任务才算完成。确认针对本次核对记录；输入资料原来的处理状态不是本次完成证据。
