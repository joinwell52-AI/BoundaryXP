# 032 预声明：来源域与评分规程

本文件为执行者在新模型输出前的来源复核，不是独立 ADMIN Gold。032 授权要求的产品验收口径不倒改 030、031、031-R1 或 Q05 原始成绩。

原 Q05：请PM列出settings.json中的配置项，并生成settings-list.md；不得更改任何配置项。

第一种解释将后句的配置项承接为前句指定文件内的配置项。来源依据是同一任务、同类对象和相邻指令的连贯关系；后句没有“其中/该文件内”明确回指，故此承接不能单凭距离认证。

第二种解释将没有容器限定的禁令理解为本任务中的配置项类别范围。来源依据是后句独立的“不得更改任何配置项”；前句仅限定列出对象，不能自动证明后句也共享其容器。源文也未明确说明跨文件，不能以一元 CATEGORY 擅自消除上述局部解释。

模拟反例：对象 x 属于本任务的配置项类别，但属于另一个文件。解释一对 x 的范围成员查询为 FALSE，解释二为 TRUE；最终竞争未解决时为 UNKNOWN。对象 y 在指定文件内的配置项范围，两种解释均覆盖，但备选计算仍须明确标记“在该解释下”，不签发最终执行许可。模拟成员不是业务观测，不读取文件。

本轮仅修改 Q05 的产品处理预期：保留列出动作、PM、产生结果、全称禁令；将会改变边界且未唯一确定的域表达为局部竞争、来源备选和最小澄清。此结果计 CLARIFICATION_CORRECT，不计“唯一域已证明”，不把澄清后的新源替换原 Q05。其他 52 份固定预期保持前序源文审阅标准。

D01–D06、D08 的明确范围必须确定；D07 的单数文件回指有两个候选，须局部保留竞争，同时保留独立读取、QA 和产物。D05 的例外不产生许可，D06 是有限对象而非全称类别。全部源文及预期在 SOURCE-EXPECTATIONS.json 登记后冻结。预期与案例 ID 不进入解析或审阅资源。

最小澄清仅询问所涉禁令的容器/域，不预选答案，不改写用户原文。用户手工补充后以新源摘要、新 run 和父记录关联重新编译，历史字节保持不变。

程序只能消费类型化表达式与来源链接：确定未限定域、竞争域和解析缺口必须可区分；不得扫描原文、标签、note 或 reason 推定范围。
