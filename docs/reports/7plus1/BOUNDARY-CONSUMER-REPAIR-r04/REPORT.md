# 边界导向 Skill 与消费者修复

本轮保留原安装、历史响应和全部已有未提交修改。隔离候选为 `0.1.0-candidate.031-r1.2-ui.42`，编译器 `031-r1-c16`；58618 仍为 ui.40，没有以定向修复替代完整产品验收。

## 修复内容

1. 解析与审阅 Skill 前置任务边界目标：必须、允许、无需、禁止、角色对象、条件范围、完成与停止；不能以是否已有运行结果判断边界是否存在。
2. 明确停止当前任务时，保留停止条件及停止阶段禁止继续的候选，关联同一任务、条件与原文来源。不得扩大为永久禁令、禁止高危问题在现实中发生，或将单纯告警、汇报、引文转换为停止。
3. 限定未决问题的真实目标：合格 `field_path` 指定被质疑字段，其他上下文 ID 不自动被污染；无有效定位及整项疑点仍保守处理。
4. 独立支持的 TEMPORAL 关系不再依赖整项事件所有条件都确定。完整事件仍可未决，关系接受不构成事件接受或执行授权。来源、上下文及技术 Proof 全部保留；缺失、拒绝对象及显式依赖仍阻断。

没有扫描原文或 note 补语义，没有修改 Schema、模型、7+1 投影规则或 Core。真实候选中的第三项禁止由 LLM 明确生成，程序没有从 STOP 自动补造 B。
