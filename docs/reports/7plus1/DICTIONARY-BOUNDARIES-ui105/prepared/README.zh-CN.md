## 对照方式与判断原则

先进行两条件配对：OFF不选字典；ON选择本组两份测试字典。相同原文、Skill、模型、推理强度及在线版本，生成和独立审阅均为新会话。仅改变可查询的字典；正常每例两组、每组生成＋审阅，共20次请求。**本次只准备材料，不发起这些调用，也不重置既有26/28请求账本。**

单独记录：生成秒数（包括生成阶段查词往返）、审阅秒数、总秒数；生成与审阅的查词次数、词条及版本；原文边界保真、字典解析覆盖、真实错误和正确保留的未决。优先观察生成能否在60秒内完成，不把审阅时间混入生成时间。

无库保持原称谓或未知内部映射，不算错误。有库查明映射是增益，但必须有实际查询证据。OFF碰巧猜中企业映射也不算有来源的正确映射；标记为无依据补充。ON没有查询、漏掉关键定义、猜掉多义性或用词典增加权限，分别记录，不合成一个虚假的PASS。

ON/OFF只支持“本组组合字典的效果”结论。可按实际查词归属说明贡献，但不能把总差异因果归给某一层；若需独立量化L2与L3，另设L2-only和L3-only条件，需单独安排调用预算。

评审只关注边界保真及可比较性，不要求完整真值表、执行安排或成功执行见证。原文的责任、交付、前提、时限和完成条件也不能因关注词义而遗漏。
