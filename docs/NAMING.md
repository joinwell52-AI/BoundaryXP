# BoundX 命名与协议标识

本文件冻结当前唯一命名组合：

| 用途 | 唯一标识 |
|---|---|
| 中文正式名称 | 界痕 |
| 英文开源与协议标识 | BoundX |
| CLI 短命令 | `bx` |
| JavaScript/TypeScript 模块前缀 | `@boundx` |
| 核心包 | `@boundx/core` |
| MCP Server | `boundx` |
| MCP 工具前缀 | `bx_` |
| 仓库源码目录 | `boundx/` |
| CodeFlowMu 内部模块前缀 | `boundx` |

“界痕”表达划界留痕、可溯可控；BoundX 承载跨领域扩展。三层语义对齐（L1/L2/L3）与 I/O/A/P/R/V/C + B 是同一语义系统，不建立第二套协议。

当前版本尚未正式启用，因此不提供旧候选名称、旧目录、旧命令或旧模块的兼容别名。历史证据中的旧候选名称仅记录当时事实，不构成运行入口、协议标识或兼容承诺。
