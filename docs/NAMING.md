# BoundX 命名与协议标识

本文件冻结当前唯一命名组合：

| 用途 | 唯一标识 |
|---|---|
| 中文正式名称 | 界痕 |
| 英文产品品牌 | BoundX |
| 协议英文名称 | Boundary Xplain Protocol |
| 协议中文名称 | 边界分析协议 |
| 协议简称与编号 | BXP / `BXP-0001` |
| CLI 短命令 | `bx` |
| JavaScript/TypeScript 模块前缀 | `@boundx` |
| 核心包 | `@boundx/core` |
| MCP Server | `boundx` |
| MCP 工具前缀 | `bx_` |
| 本机工作目录 | `D:\boundx`（独立仓库根目录） |

“界痕”表达划界留痕、可溯可控；BoundX 承载跨领域扩展。三层语义对齐（L1/L2/L3）与 I/O/A/P/R/V/C + B 是同一语义系统，不建立第二套协议。

上述标识用于当前独立项目。研发预览不等于公开发布；不提供其他项目的命令、目录或模块兼容承诺。

2026-09-16：按 ADMIN 确认统一协议名称。BoundX 是产品实现，BXP 是协议。Xplain 是命名采用的品牌化拼写，不改写为 Explain。名称调整不改变 7+1 语义、协议版本 `0.3.0-draft.2`、产品版本 `1.3.0-preview.0`、Schema、208 条冻结向量或 `boundx-task/v1` / `boundx-result/v1` 技术标识。

The protocol is **Boundary Xplain Protocol (BXP)**; the product is **BoundX**. This is a naming-only update, not a protocol revision or product release. Existing wire identifiers remain unchanged.
