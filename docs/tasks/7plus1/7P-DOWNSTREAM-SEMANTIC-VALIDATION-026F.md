## 4. 共用实际语义核心，隔离自动入口审计


## 6. 三类语义对照的最低要求

1. 对象边界：`核对在用设备编号` 与 `在库房核对设备编号` 必须区分完整名词对象和地点；再加入等义改写与对象／地点交换对照。
2. 条件用途：`QA必须复核报告，复核通过后PM才可提交` 与 `历史记录显示QA曾复核报告，本次只统计日志` 必须区分当前复核要求与历史事件。另验证“只规定审批后才可执行”不凭空新增审批义务。
3. 目的用途：`报告必须发送给QA用于复核`、显式另加 `QA必须复核该报告`、`报告发送给QA存档`、`文档中引用一段复核说明` 的输出必须保留原文明确差别，不全部映射成同一动作／角色。

这些句子是测试设计示例；正式候选图和期望按现有合同建立并在修复前冻结，不允许直接把例句写入运行逻辑。
