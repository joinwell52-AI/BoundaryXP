## 4. 必须实际实现的首选方法：模型语义结构驱动的组合解析

不是再造一层与候选图平行的产品架构。以下是生成现有候选图的算法职责，可用现有类型和数据结构实现。

### 4.1 来源及标签规范化

保留原文、原始 token 索引、码点偏移、原始头节点索引及每个任务的标签体系。统一标签前先核对方向、0/1 起始索引、谓词 frame 身份和 tokenization 对齐。

SRL 的 ARG0/ARG1 不是所有谓词中恒等的执行者/对象；按所用标签规范及谓词结构生成有类型假设，不能不分谓词就硬映射。SDP 也必须按实际模型标签表处理。

同一字符串在不同位置是不同 mention；同一动作词出现在主句和定语中不能合并成一个主任务事件。抽象节点允许以若干真实片段及推导路径追溯，不能伪造不存在的连续原文 span。

### 4.2 从模型已给出的谓词和边建立局部结构

以模型的 SRL frame、SDP 边及真实依存/短语结构为证据，建立谓词候选和其论元候选。每条边保留具体 frame ID、token ID、原标签和连接路径。

存在模型证据时直接消费，不能先用词表生成一套不同结构再拿模型为它背书。模型遗漏的结构可以由下述固定组合规则补出，但必须标成程序推导，不计为模型直接能力。

不得枚举全篇任意节点的笛卡尔积。无关系证据的“附近对象”不能任意配给动作。

### 4.3 层级和所有权保留

利用短语包含关系、补语/定语连接、依存与语义角色记录，保留主句、修饰、条件、输出内容、引述、目的、历史陈述等用途。

例如“被检查的服务”中的检查事件可以存在，但不因此新增一次当前检查命令；反过来，同一事件有时间前提用途，不等于必须删除其独立的当前任务用途。两种用途应分别有来源见证。

多种合理层级可以竞争，不能只为通过已知案例把同名谓词全部压成主句或全部压成定语。

### 4.4 论元填充、修饰附着及并列组合

实现带类型的组合操作：将模型给出的论元连接到对应谓词；将修饰附着到真实目标；沿明确并列连接组合事件或对象。

共享论元只沿有见证的并列/省略结构提出，记录继承起点、路径和范围。跨过另一个有独立对象的谓词时不得凭距离借用其对象。组织责任不自动变成组织者亲自执行所有动作。

方法允许有限语法和操作词词表，但每条规则必须描述可复用的结构条件、输入和输出，而不是某个任务句子的模板。规则/模块的数量本身不是成败标准，是否保真和跨表面表达有效才是。

### 4.5 否定、模态、条件和数量绑定

算子处理必须输出：来源标记、算子含义、被支配命题/事件、操作数、极性、必要/充分关系及归属证据。

需要区分：

```text
必须执行 / 允许执行 / 不要求执行 / 禁止执行
条件前提 / 时间先后 / 整项任务完成条件
资源上限 / 产物内容数量 / 分类阈值
当前任务要求 / 文档中要写的要求 / 历史事实
```

“只有 X 后才允许 Y”不能推成“必须执行 X”，也不能把 X 满足当成原文未授予的无条件许可。“不要求 X”不是“禁止 X”。“送给 QA 作复核”不能无条件添加一个独立强制复核命令。

组合须保持作用域嵌套及非交换性，不能把 IF、ONLY_IF、AFTER、AND、OR、NOT 扁平化为同一种条件边。

### 4.6 指代与跨句组合

使用明确句子、段落、mention、实体类型和支配关系构造候选指代集。记录跨句关系不是原模型直接输出的事实。找不到唯一支持、存在多个合法先行项或源文没指定执行细节时保留相应未决/未指定，不凭最高相似分数或最近距离填写。

传播的“必须”不能单独使一个词成为业务谓词；上下文出现过对象不能证明其属于当前动作。这些已验证限制继续保留。

### 4.7 有界竞争而非候选污染

保存有来源的合理备选、去重、类型兼容与互斥组。可做保真规范化、结构不合法过滤和可追溯的有界搜索；不得靠穷举所有含义虚增召回，也不得用任务 ID、答案、当前评测结果选择分支。

设定并登记搜索/候选预算。超预算必须记录哪些假设未覆盖，不能静默丢弃再声称完整。候选排序只是解析假设排序，不是 ADMIN 授权认证。

## 5. 一个允许的独立替代路线：抽取式 UIE

本任务同时授权在独立环境测试一个官方预训练抽取式 UIE 模型，优先 `uie-m-base`，使用固定的事件—论元抽取结构。不得换成名称相近的生成式 PP-UIE/聊天大模型。

这不是预设 UIE 会成功，也不是串联更多模型碰碰运气。它与第4节路线独立运行，用来比较两种可执行方法：

```text
方法一：SRL/SDP/短语结构 → 组合语义
方法二：UIE 事件及关联字段抽取 → 显式作用域组合
```

抽取结构按事件实例组织，例如动作及其执行者、对象、结果、接收者、依据、条件、数量限制；必须保留模型实际返回的父子关系和原文位置，不得将多个独立字段列表任意配对。事件触发词类型、查询结构和阈值在评测前固定。

UIE 抽出的“条件文字”不等于已经识别了条件支配关系；仍按第4节明确规则核验组合，并单独计贡献。

只有证据显示互补时，才允许一个统一、预先说明合并规则的混合版本；不允许按 case 选择两路中正确答案。总共不超过两类独立模型路线，不继续增加第三、第四种框架。已有 MRP 只复用026E原始结果作历史参照，不重复安装、重跑或将其改名再做。

## 8. 实验必须能回答：能力到底来自哪里

在同一输入、同一原始模型输出上分别记录：

1. 模型直接关系，不经过组合；
2. 加标签与位置规范化；
3. 加局部论元和层级组合；
4. 加作用域、数量及文档指代组合；
5. 最终完整语义结构。

至少做SRL、SDP和成分层级证据的逐项消融；缺少某个任务头时记录 `NOT_AVAILABLE`，不制造消融成绩。模型不提供置信度时记录未知，不能自己填概率。

分析单位必须包含完整语义断言，不只数边。恢复率与错误率须同分母同口径，模型路径支持、候选召回、最终解释正确性分开。

026E 的切分/整句结果直接复用为历史对照；完整句子仍是方法实现的可选输入组织，不预设它必然优于切分。需要新采集任务头时保留完整原文位置，不在改变分句、词表、标签映射等多处之后，把收益全部归因于分句。

正确节点未产生、原模型没有关系证据、模型有关系却被转换丢失、作用域表示不足、组合错误、评测错误，分别归因。不得从“这版算法失败”推导所有 NLP 都不可能。

## 9. 32条机制对照：检验方法，不靠修原句

建立8组、每组4条，共32条预先登记的机制单元测试：正例、语义相反反例、等义改写、组合变体。

八组为：依据与对象；主句与定语；支持动词与内容谓词；必须/允许/无需/禁止；必要条件与时间先后；并列与共享对象；输出内容/引文与当前任务；指代及数量目标。

这些是方法单元测试，不称新盲测。只在语义确实等价时要求结构等价；主动/被动需保留真实施事，删主语、换代词、移动条件可能改变或模糊语义，不能机械当等义变换。

每个通用修正至少需跨两个表面不同的例子和相反例验证。文件名、人名、版本号替换不得改变关联角色；不可建立这些字符串的答案表。

- 每案时延、峰值内存、模型调用/缓存数、候选规模及超预算数。

最终状态：`SOURCE_SEMANTIC_026G=PASS / PARTIAL / FAIL / ENV_BLOCKED / REVIEW_REQUIRED`。

- **PASS（仅本次已检验范围）**：可运行程序从原文自动获得60/60完整来源语义，32条机制对照全部正确，无无依据唯一解释、错绑定、错误命令提升或伪造来源；350条扩展已完成，未出现已确认的语义反例，全部待审/未复核数量如实列出。存在未复核条目时不得把PASS扩展为“350/350语义已证明”；若其影响核心判断，使用REVIEW_REQUIRED。
- **PARTIAL**：有可复现的跨类别改善，但仍存在明确解析缺口、错误解释或扩展反例。明确能解决什么和不能解决什么。

所有状态均不得声称 `BOUNDARYXP_PRODUCTION_READY=true`、不得声称下游已修好，不把文件完整性检查当语义证明。
