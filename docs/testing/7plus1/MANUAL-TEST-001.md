## 过程与计算检查

1. 两个检查的执行者、对象、各自产物和接收者正确绑定，不互换或合并。
2. QA复核的前提是两份报告均已提交；PM生成汇总的前提是复核通过。不要倒置条件方向。
3. QA复核使用本次dev.md和ops.md；PM汇总使用同两份报告，应保留产物使用依赖及真实来源。
4. 两份报告均提交QA属于AND，不是任意一份提交就足够；最终完成同样是AND，不能只凭summary.md存在判定完成。
5. 未提供实际执行观测，因此不能宣称任务已完成、条件已满足或可以访问生产环境；缺少观测保持UNKNOWN。技术接受、模型审阅及未命中禁止都不是业务授权。
6. 逐项比较原文、LLM原始候选、独立审阅、技术检查、IR、7+1 JSON和中文；记录首次遗漏、多造、错误RESOLVED及真实未决，不能以Schema合法替代语义正确。
7. 记录解析与审阅各自用时、调用次数、运行版本和模型设置。重复测试使用相同原文；不得改写输入去迁就解析器。
