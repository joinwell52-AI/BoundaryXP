## 八、高危与停止条件计算

```text
H → REQUIRED(PM立即停止本次核查与汇总)
H → REQUIRED(PM向ADMIN汇报高危问题)
Z → FORBIDDEN(继续本次核查与汇总)
```

| 条件输入 | 计算结果 |
|---|---|
| H=true | 停止与汇报义务都触发 |
| H=false | 本条高危触发义务不激活 |
| H=UNKNOWN | 触发值UNKNOWN，明确规则保留 |
| Z=true且提出继续核查/汇总 | 命中禁止 |
| Z=false | 未命中停止期间这条禁止；不自动授予许可 |

高危是停止边界的触发，不能将H强行设置false。立即是停止事件的定性要求，无数值期限，不换成0秒。本原文明确分开汇报义务，没有要求汇报也立即。
