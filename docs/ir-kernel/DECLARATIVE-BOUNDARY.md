# 在线声明式边界合同 r02

运行配置 DECLARATIVE_BOUNDARY_R01；IR接口 candidate-ir/2.0，唯一Core不变。

在线交付是一份完整、可计算、有真实来源的任务边界。变量保持未赋值，事件表示规范中的动作类型或身份，状态表示判断条件；都不宣称实际发生。原文给出的数量、角色、对象关联、全称范围、例外、固定选择、重试门、期限、完成及停止定义必须完整表达。

传输格式boundx-boundary/2：沿用同版IR语义与算子；引用只写全局唯一ID字符串，要求的空note不输出。expressions把literal、unit、bound_variable收在parameters对象；三者全为空时只写parameters:null，程序机械还原三个null；否则三字段均保留，false和"0"不得当空值。其他字段不变。程序仅补引用kind、空note及这三个空参数，不猜引用、不补语义。旧boundx-boundary/1响应保持可读，不继承新模型成绩。

来源、身份、模态、作用域、数值、单位、端点及binder不可省略。ID使用短的全局唯一标识，如e1、x1、r1；含义在类型、算子、论元与label中，不反复写长英文句子作为ID。同一常量和相同作用域、相同来源的表达式复用；跨作用域或来源不同不强行合并。模板只定义一次，选择与索引保留，不展开实际执行。短reason只解释问题，不重复整句原文。

审阅接收同一紧凑候选、完整原文、合同与算子表；格式/类型/引用由程序执行同版Schema校验，审阅正文不重复整份解析Schema。审阅输出自身Schema仍通过CLI交付。宿主摘要绑定展开后的IR，v2摘要按对象键排序，数组顺序与所有字段值保留；模型原样回传，不自行算摘要。

解析只输出IR。不得附加另一份7+1、数学报告、真值表、测试用例、执行实例快照、联合见证、PM安排或自定具体时间。不要求证明整案存在正常完成安排。程序可以计算封闭的集合和常量表达；等待PM规划或实际证据的表达保留变量和规则，不因缺少观测而判定边界缺失。

区分：边界结构有效；独立审阅支持；本次人工语义核对；特定规划符合边界；实际执行符合边界。这些不是同一个结论。未命中禁止不代表许可，局部检查不能冒充全案核验，business_decision/execution_authorization始终null。

## 来源、身份及规则

source_table保存精确quote及occurrence，节点引用source_refs；不复制引文到每个节点。IR节点存一次，各7+1视图只引用。ENTITY身份不按相同label合并；生成、消费、复核和交付同一本次产物保持关联。BASIS引用只保留名称、版本与用途，不读取制度正文。程序不扫描原文、label、note补答案。

TASK_FIXED表示任务内固定的未知选择，不替执行者选值。固定选择必须约束全部相关实际操作：不能先用“对象等于选择”过滤域，再宣称域内对象都等于选择；这会漏掉换对象的违规操作。域按原文明示的主体、操作、业务对象类别限定，再对域内每个成员检查身份。其他主体或无关业务读取不自动计入该序列。

重试保留首次义务、重试许可、总次数与重试次数的偏移、直接前次失败已成立的开始门。用模板及索引变量表达，不展开实际次数，不创建成功或失败观测。有限序列声明不是实际执行记录，也不能代替对额外违规操作的约束。

必要门在受限动作开始时检查；后来成立不能追认。独立义务不可因必要门未成立而删除。全局规则覆盖任务相应事件域，不缩成当前已列动作。完成定义保留方向；当且仅当使用IFF。时间区间保留单位、严格端点及整体目标。

## 紧凑审阅输出

审阅只加载审阅Skill、同版合同、算子接口、原文及候选。candidate_sha256必须原样回传宿主audit_binding中的摘要，不自行计算。examined_source_ids明确列出实际核对的全部来源；support_groups按共同理由列出已完整支持的节点ID，field_path=""表示整节点。序列另以其template ID、field_path="sequence"核对。问题用reviews、issues、omissions指出精确目标、来源和理由；缺失目标不默认通过。支持分组只压缩输出，不缩小审阅范围，不重写IR或执行安排。

无问题时问题数组为空，不另写每节点长篇解释。原文明确但漏表达是遗漏；变量尚未选择或执行尚未发生不是歧义。不能要求候选补执行时间、完整见证或数学报告才能得到SUPPORT。

## 统一样例（方法示意，不是测试答案）

“从许可集合中恰选一项且不得更换”：对象变量x的域是许可集合，binding_mode=TASK_FIXED；相关实际操作的对象等于x。保留x，不选择具体值。

“仅前次失败后可再试，额外至多n次”：重试实例启动⇒直接前次失败已成立；尝试次数在[1,n+1]的整数域。没有要求重试一定发生。

“全部报告通过后才能生成和交付”：同一个全称通过条件分别绑定生成、交付开始；保留报告身份、量词域及两个受限动作，不创建某时刻通过的记录。

“完成当且仅当Q且D”：保存C↔(Q∧D)。没有实际状态时不判断完成；无需展开真值表。

完整证明、正反观测、真值表和手工见证仍可用于离线验证。收到PM规划后调用既有Core对相关及跨任务组合规则核验；未提供完整对象或状态则具体标明未决，不伪造通过。
