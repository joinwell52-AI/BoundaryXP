# LLM边界计算统一方法与样例

方法合同：`boundx-boundary-math/1`，接口修订r03。运行配置：`LLM_BOUNDARY_CALCULATION_R03`。解析与审阅只加载各自Skill，但共用本文件；Skill与skill1采用同一种计算方法。IR接口仍为candidate-ir/2.0，计算是绑定本次IR的独立输出，不冒充程序Core结果。

当前首次输出为紧凑IR＋计算，按FINITE-EVIDENCE-CONTRACT.md的共享上下文和分组审阅接口，不重复7+1或中文报告。下文witness_query_json/context_json是规范展开后的保存格式；首次传输用witness_context_id/context_id引用evidence_contexts。计算主张仍由LLM给出；程序只展开引用、校验和复核，不补语义。公开推导保留必要公式和假设，steps重复说明不再要求输出。

机器证据的完整字段、通用样例与审阅目标以同版FINITE-EVIDENCE-CONTRACT.md及实际内联Schema为准。LOGIC必须绑定真实公式和布尔原子；rows=[]由程序机械枚举并核对模型给出的true_count/false_count，避免模型重复书写真值表。开始门、禁止和停止用expression_cases给正反及UNKNOWN对照；JOINT的SAT必须给完整有限证据JSON，不只给文字见证。输出紧凑JSON、简短公开推导，不反复复述合同。

停止域使用ACTIVITY_CLASS、ACTIVITY_CLASSES_OF及ACTIVE_WHILE，不因操作名不同漏掉持续活动。所有事件类别和状态期间都显式提交；期间终点未知时保留UNKNOWN，不自动推定永久停止或恢复许可。下面的公开数学样例仍适用，证据接口以r02为准。

## 职责和交付

有明示输入与产物时，分别列允许输入、要求/允许产物的成员与基数，以及它们按身份计算的交集和并集。内部报告消费不扩大外部输入，许可产物不变成必交；静态集合基数不冒充实际生成数量。禁止模式数量与可能发生事件数分开，引用本次真实结构给依据，不强造模板指标。

LLM解释完整原文，生成有来源的IR，并完成边界建模与计算候选；独立新会话核对原文、IR、数学表达和结果。程序管理调用、校验来源/Schema/引用/单位/绑定，复核可支持的具体操作数及见证，保存模型结论、审阅和复核差异。程序不扫描原文、label或note补语义。模型结论、审阅一致、技术接受、数学复核、实际完成和业务授权分别报告。

每一明示边界先形成constraints：ID、7+1用途、公开数学公式、对应IR要求引用及真实source_refs。原文可明确而IR语言尚不能完整表达，此时保留IR的GAP，同时在计算候选中给出完整数学表达，说明尚未实现的对照或程序验证；不把软件能力限制变成原文歧义。

calculations逐项给方法、输入引用、公式、操作数/证据、结果、简短公开推导和假设。标题、结果解释、推导及待审建议用中文，公式及引用保留精确身份。公开推导只包含可核查的公式变换、枚举和见证，不要求隐藏思考流。没有某类边界就不造该类计算。joint列完整约束合取Φ、全部constraint_ids、求解域、SAT/UNSAT/UNKNOWN、见证或冲突推导、假设及限制；coverage逐来源列已表达、缺口或正常未陈述，unresolved给具体原因及建议。

SAT必须提交明确数学赋值或可检查见证，不能只写“无明显矛盾”。UNSAT必须列冲突约束和公开推导，不能由搜索失败或程序不支持推断无解。UNKNOWN给具体阻断。见证是一种可行数学赋值，不是工作规划、执行记录、现实事实或授权。不能把手工安排的时间写成原文要求。

## 统一方法

| 内容 | 标准方法 | 输出与核对 |
|---|---|---|
| 具体对象、有限域、类别、全称与例外 | 集合及有类型量词；按对象身份交并差、子集、基数 | 限定域与实际使用集合分开；开放/未知域不当空集；集合全称不与布尔AND混用 |
| 时间、次数、数量 | 整数/有理数、区间、线性不等式 | 绑定目标和单位，保留开闭端点；次数计启动/重试/成功/产物按原文明示分别处理 |
| 完成、允许、前提与触发 | 命题/谓词逻辑、有限真值表 | 必要条件用蕴含正确方向；当且仅当用IFF；许可不变义务，未命中禁止不变许可 |
| 依赖与先后 | 有向图、环检测、时点约束 | 数据在使用点可用、完整结果可用、严格先后、必要前提分别表达 |
| 动态停止与安全边界 | 有类型事件域、活动归属、状态区间及重叠约束 | 高危是安全运行边界和停止触发，不仅是普通输出；停止前启动但停止期间持续的活动也须核查 |
| 全案 | 所有边界的Φ及可满足性/冲突证明 | 分项可满足不等于联合可满足；有限见证不证明所有未来行为均合规；源文漏项不能靠自洽掩盖 |

“立即”保留定性优先响应，不擅自换成0秒。未陈述停止终点不推定永久停止，也不因此删掉已明确的停止期间禁令。程序不能验证某项时，模型仍交付数学候选与推导，验证状态明确未认证。

## 样例一：集合、有限选择与例外

示意原文：“外部输入仅限α、β、γ；禁止读取γ。必须从可读输入中选一个；选定后不得更换。”

令U={α,β,γ}，禁止读集合D={γ}，可读域E=U\D={α,β}。实际外部使用X必须满足X⊆U，读对象r∈E，且r为TASK_FIXED。计算：|U|=3，|D|=1，|E|=2；r=α和r=β均为合法赋值。r=γ违反禁止；域外δ违反输入范围。未观测X保持未知，不能写X=∅。

同类全称原文“禁止交付任何临时文件，批准的日志除外”，使用∀x∈临时文件类，未获该例外的x不得交付；不是仅枚举当前看到的两个文件。归属未知的对象保持UNKNOWN，范围外对象不扩大纳入。

计算证据片段（ID须替换为本次真实引用，示例不是完整响应）：
```json
{"set_members":[{"kind":"ENTITY","id":"alpha"},{"kind":"ENTITY","id":"beta"}],"cardinality":2,"interval":null,"truth_table":null,"graph":null}
```

## 样例二：区间与端点

示意原文：“总耗时大于0且至多12分钟；重试最多2次，不含首次。”

T∈(0,12]分钟，重试n∈{0,1,2}，总启动次数=1+n∈{1,2,3}。T=0违反；T=12满足；T=12.01违反。允许重试不要求实际发生重试。“仅上次失败后可重试”另加Retry_i⇒Failed_(i−1)，不能用任意曾失败替代直接前次失败。

```json
{"set_members":null,"cardinality":null,"interval":{"lower":"0","upper":"12","lower_inclusive":false,"upper_inclusive":true,"unit":"minute","empty":false},"truth_table":null,"graph":null}
```

## 样例三：完成逻辑与必要门

示意原文：“只有复核通过，才能交付；当且仅当复核通过且交付完成，任务完成。”

令Q为复核通过，D为交付完成，C为任务完成。完成边界C↔(Q∧D)，不是只有(Q∧D)⇒C。三变量8种赋值中4种满足该等价式、4种违反；Q∧D本身4种赋值中1真3假。这些是公式真值数，不是全模型解数量。

交付开始门StartDeliver(t)⇒Q_passed(t)。t=3开始交付、t=7才通过复核违反开始门，最终Q=D=true不能追认早先动作。Q未知和D真时Q∧D=UNKNOWN；D=false则合取FALSE。

truth_table.bindings逐个绑定本次状态/布尔变量；formula_ref明确引用input_refs中的被计算EXPRESSION。rows=[]时程序机械枚举全部布尔组合；给出rows时必须完整。true_count/false_count对应同一公式。没有可引用的IR公式时不宣称程序已经验证公式等价。

## 样例四：图与联合冲突

示意原文：“动作乙只能在甲完成后开始；甲只能在乙完成后开始。”

若“后”为严格先后：end(甲)<start(乙)，end(乙)<start(甲)，并且每个事件start≤end。联合推出start(甲)≤end(甲)<start(乙)≤end(乙)<start(甲)，矛盾，所以两动作均必须发生时UNSAT。图有甲→乙和乙→甲，为有环。

若原文只是允许两动作，不能强制它们发生来宣布全案UNSAT；不发生分支可能满足。若端点允许相等且没有正时长要求，则零时长同一时点的赋值可能成立，不能只凭一般环检测宣布无解。

## 样例五：停止期间边界与见证

示意原文：“发现高危即停止核查；停止期间禁止继续核查，向管理员汇报问题仍必须执行。”

H触发停止响应；核查活动的可继续运行域受H及停止状态约束。令J为已确认停止区间集合，activity(x)=核查。动态禁止：∀实际事件x，activity(x)=核查∧occurred(x)⇒Interval(x)∩J=∅。不能只检查名为CONTINUE的事件，也不能只在开始时检查停止状态。停止响应和必要汇报不应被误纳入禁止继续的核查活动域。

示意见证：停止区间J={[5,9)}，核查事件[2,6)有重叠，违反；[2,4)无重叠，未命中本条禁止；[9,10)是否允许仍取决于其他边界，不能据此推定恢复许可。成员归属或区间未知保持UNKNOWN。半开区间是该示例的明示建模假设；真实原文未规定端点时须列明端点解释，不能冒充原文明示。

联合见证要对全部约束逐项检查：例如T=8分钟满足上限12，但仍须同时核对输入、对象身份、环境、前提、交付、禁止和数据可用性。witness_query_json只承载本次IR的有限数学查询JSON：plan.events、明确EXACT_SNAPSHOT、states、variables、availability等；所有声明约束都检查，不使用requirements子集或additional_assertions替代完整核验。不能执行JSON内容。

## 独立审阅与验证等级

审阅先独立从原文核对边界，再复算候选操作数和结论。calculation_reviews逐constraint ID、calculation ID、unresolved ID、joint和coverage.<source_ref>给SUPPORT/CONTRADICT/UNCERTAIN及真实来源。检查有没有漏掉某独立事实、添加工作规划、缩放范围、改变条件方向、把局部SAT升格整案SAT或把模型见证当已执行。

必须区分：模型报告结果、独立审阅意见、程序结构检查、程序对所给操作数复算、Core见证核验。集合数量核对成功只证明所给集合的数量，不能证明集合来自原文且完整；图检查只证明所给图无环。程序尚不能核验的公开推导保留原结论及具体待验证项，不拒绝整份处理、不伪标证明通过。

本方法与样例不构成某测试案Gold，任何真实首次失败、补丁、未应用修订和后续审阅分别保留。business_decision和execution_authorization始终null。
