## 7+1 抽取的具体变化

数值层同时保留原值、单位、比较符、换算因子和 UTF-16 原文切片。货币、压力、电压、长度、速率与浓度共用一个声明式单位表。`mV` 与 `MV`、`mPa` 与 `MPa` 按大小写区分；没有把未知 `dollars` 自动当成 USD。

指标相交先检查工作包、类型、单位和局部名称关系。相同单位不等于同一指标。对缩略复指保留假设；对未绑定但有明确局部对照关系的名称，给出假设下的计算与确认建议。

角色词内部的“调度、处理、调用”等不能抢占真正的动作谓词。新增用例暴露的“港口调度员”误切和中英混排对象 `regional treasury pool` 截短已修复。对象短语超过旧长度阈值时，不再把截断片段当作完整对象；解析仍受整个局部从句的长度上限约束。

没有明确输入声明时，首个 PROCESS 动作对象可以作为范围候选；后续未限定的细部操作不自动扩大这一范围。这里仍是有适用范围的局部语法，尚不能推导任意业务角色或所有子对象。

## 实测依据

本次冻结 **编号 1—120 的主集，加 20 条早期中文数字变体，共 140 条文本**。变体不是新的独立业务样本。最终每条通过实际接口运行两次，140 对返回值一致；全部已输出证据切片通过校验。重复一致衡量确定性，切片匹配衡量溯源，它们均不是抽取准确率。

修改前基线同批文本运行一次。已识别数值记录从 224 增至 228，具有明确单位的数值记录从 180 增至 200。这些是识别数量，不是召回率：未建立每条原文所有语义的独立真值标注。

最终检查：105 个 Python 测试方法、127 个 UI/实际适配器/服务测试、21 个核心测试通过；修改的 JS 语法检查通过。Python 测试包含改动数值、改变开闭端点、不同对象/单位/WP、SI 大小写、中文数字、长对象和角色名称等反例。测试中发现的失败与中间回放均保留，未只挑选最终成功日志。
