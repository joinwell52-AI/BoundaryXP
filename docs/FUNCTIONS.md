# 界痕 · BoundX 功能说明

**1.2.0-preview.1 应用层新增本地界面与模型整理入口**，见[界面使用指南](UI-GUIDE.md)。下面的 1.1.0 描述说明计算内核；内核仍不直接解释全文，模型提取在新增应用层完成。有限布尔分解功能尚未接入本页图形表单。

当前产品版本：1.2.0-preview.1。界痕的计算内核独立、无状态，接收原文和人工或 AI 整理的结构化映射，返回发现、依据、建议及符号反例；内核不直接理解全文、不作业务裁决。新增本地界面承担模型整理与记录导入导出。

## 两个使用环节

**任务授权方（例如 ADMIN）下发前：** 检查七参数是否提供原文映射，提示应由授权方明确的项目。现有纯文本入口不自动提取语义；原文已有内容应补引用，不应凭未映射就要求重写。

**负责人（例如 PM）规划和派单后：** 比较任务与规划，检查每份派单的动作差异；通过新增分解接口计算交付充分性、额外前提及上下游输入缺口。需由宿主显式调用，工具不会自行监听任务。

## 功能、输入与实际输出

| 功能 | 需要什么输入 | 会返回什么 | 当前限制 |
|---|---|---|---|
| 七参数检查 | 原文及 I/O/A/P/R/V/C 的引用 | 未映射位置、补充建议 | 不评价已填内容的语义充分性，不打理解分数 |
| 动作差异 | 原基线与规划、各派单的 actor/verb/target | 新出现的动作元组及原文 | 正常分工、同义标签也可能提示，不能直接认定越权 |
| 总规划完成条件变化 | 条件标识与引用 | 新增/遗漏、独立合取条件的符号反例 | 不自动识别同义条件，不解析自由文本逻辑 |
| 原要求追溯 | 原要求 ID 与子任务 covers | 未声明承担者的要求 | 有关联不等于充分落实；无关联不证明实际遗漏 |
| 整体交付计算 | 根要求、子任务产出、完成组合、环境关系 | 局部完成但原交付缺失的赋值 | 依赖正确的布尔映射，不是执行成功证明 |
| 额外完成前提 | 同上 | 原交付满足但新组合不满足的赋值 | 内部步骤可能合理，需负责人说明依据 |
| 子任务接口 | 输入前提、直接上游产出及依赖 | 上游承诺不能保证输入的反例 | 外部输入要显式说明；不算完整运行可达性 |
| 图与模型异常 | 依赖图、逻辑表达式 | 有向环及矛盾模型；原规划接口另提示未知依赖 | 分解接口未知 ID 作为输入错误拒绝；有环不证明线上死锁 |
| 回应核对 | 发现与立场/理由/引用 | 未回应 ID、awaiting_response 或 responded | 不验证理由属实；responded 不等于问题解决 |

## 七参数

| 参数 | 描述 | 例子 |
|---|---|---|
| I | 输入、检查对象与范围 | FCoP、MCP、SKILLS、角色权限、轨机 |
| O | 产出与接收方 | 向 ADMIN 提交报告 |
| A | 允许动作 | 检查、建议；修改是否另行授权 |
| P | 责任分工 | PM 分解并组织团队 |
| R | 时间、调用量、费用等资源 | 上限或超限申请办法 |
| V | 版本与证据来源 | 提交号、实例、证据时间范围 |
| C | 完成与停止条件 | 检查完成并汇报；无法验证项如何处理 |

七字段不是七个数值指标。界痕不输出“填满即通过”或“理解得分”。

## 接口如何选

| 目的 | 函数 | CLI 子命令 | 通用 MCP |
|---|---|---|---|
| 原任务检查 | reviewBoundX | task | bx_review_task |
| 规划和派单差异 | reviewPlanBoundary | plan | bx_review_plan |
| 子任务契约计算 | reviewDecomposition | decomposition | bx_review_decomposition |
| 回应核对 | boundaryResponseStatus | responses | bx_check_responses |

输入协议见 [项目首页](../README.md)和[分解手册](DECOMPOSITION.md)。普通观察保持 business_decision=null、semantic_status=requires_human_review。非法结构、原文引用不实或超过边界时返回错误，不能当成无异常。

## 产品与宿主边界

界痕提供算法、协议和建议；宿主负责提取映射、身份与基线授权、启停、调用时机、记录保存、提醒送达、催办、申请流转和接班。各宿主需独立实现与验证适配；本项目不自动注册到其他应用。

旧接口建议支持中文和英文；新分解接口及本地界面当前为中文。布尔域最多12变量；不计算预算最优、执行调度或所有自然语言歧义。没有自动更新；图形入口详见 UI 使用指南。
