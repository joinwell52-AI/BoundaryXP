# rc.12 · B353

Windows：`0.4.0-rc.12`（`latest` / `next`）；Linux：`0.4.0-rc.12-linux.1`（`linux`）。保持 21 个 MCP 工具、17 项资源、宿主 LLM 模式、L2/L3 完整目录字典和中英文七步报告。

## 更新内容

- **漏交运算类型**：只在已提交字段完整且唯一匹配预算、依赖图或布尔蕴含结构时补全。显式空值、未知类型、额外字段和歧义不会被猜测修复。
- **路径引文重复转义**：仅去除一层额外反斜杠转义，恢复后的引文必须在原引用节点中唯一逐字匹配。有效原引文不改；不模糊匹配、不改绑节点。
- **预算明细共同字段**：仅从外层明确且无冲突的资源、单位、期间和范围继承。金额、额度、实例和证据不补造。
- **预算余额回执**：完整、固定金额、加法预算通过核验后，原生 Core 返回精确余额。例如 180＋160＝340，额度 500，余额 160。

原始模型响应、原候选、补全记录和计算输入分别保留。LLM 独立判断与计算器复核仍分开记录。程序核验不保证语义抽取正确，业务裁决与执行授权保持 null。

## 安装和升级

[npm 同页中文与英文安装](https://www.npmjs.com/package/boundaryxp-mcp) · [Windows 中文](npm/INSTALL.zh-CN.md) · [Windows English](npm/INSTALL.md) · [Linux 中文](linux/INSTALL.zh-CN.md) · [Linux English](linux/INSTALL.en.md)

固定版本配置不会自动改成新版。管理安装按自己的更新设置检查和激活；运行中的连接不会因发布而被强制替换。运行包摘要和原生模块均变化，管理安装需用目标版本安装器及 `--migrate-data <原数据目录>` 进行校验复制；先完成在途任务，保留原目录，不先卸载旧版。

产品包交付编译核心、可读适配器、页面和语义资源；不交付原始 JS Core、C++ 实现、调试符号或客户任务。Windows x64 要求 Node ≥22.18；Linux x64 要求 Node ≥22.19、glibc ≥2.36。暂无 macOS/ARM64 包。

MCP 保持完整项目列表。本轮没有接入独立工作台的历史分批加载和评审后另行生成文档功能，不展示这些未支持按钮。既有双语分析报告、导出及复验保留。

## English

rc.12 synchronizes the B353 input preparation contract and recompiles the native Core for Windows and Linux. Missing operation discriminators are recovered only from complete, unique supported structures. One extra path-escaping layer is removed only when the recovered quote uniquely matches its original node. Allocation entries may inherit explicit, non-conflicting enclosing budget identity fields; values and evidence are not invented. Complete fixed additive budgets receive an exact remaining-budget receipt.

Original responses, candidates and adaptation records remain separate. LLM interpretation and deterministic calculation are independent records; successful calculation does not establish semantic correctness or execution authorization. Both platforms retain 21 tools, 17 resources, bilingual reports, dictionary import, and zero-model-request rechecking.

Publishing does not hot-swap an existing connection or erase tasks. Use the target-version installer, the same installation/data paths and explicit copy migration. The package contains a compiled Core with readable adapters/UI/resources; original Core source is excluded. The MCP integration retains its complete project list and does not expose the separate workbench's deferred history batches or post-review document-generation feature.
