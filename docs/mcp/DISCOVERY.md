## 产品概述 / Product overview

BoundaryXP（界痕）用于AI Agent和多角色任务的7+1边界分析与原生计算复核；支持完整父子任务、多个DEV子任务、L2/L3字典、证据报告和本地工作台。Windows x64，中英双语。默认由当前宿主 LLM 分析，经 MCP 提交给原生 Core 复核；用户自己的模型 API/profile 为可选模式。
