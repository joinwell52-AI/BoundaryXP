## English

rc.11 adopts B348 complete Chinese and English reports from a single analysis, sharing evidence, verdicts and native calculation inputs. `bx_result_get` accepts `zh-CN` or `en` and exposes single-language and bilingual Markdown artifacts. Legacy monolingual reports remain readable without invented translations. Optional API settings verify connection and discover models before saving; default host-LLM operation still needs no separate API key. The evidence panel is collapsible.

Windows native checks passed 682 calculation, 104 model-contract, 25 host-contract and 19 parser cases. Adapter results were 59 pass, zero fail and seven explicitly skipped historical fixtures. Isolated rc.10 migration/rollback retained 60 original files, configuration, dictionaries, failures and legacy reports. A real Codex-host response for two independent DEV nodes produced one VERIFIED and one VIOLATED calculation; revision 7 remained readable after revision 8 recheck. Final Windows, Linux and Docker checks replayed that response and are not additional model analyses or semantic-accuracy samples.

Actual browser downloads of Chinese, English and combined Markdown matched the saved MCP artifacts byte for byte. Linux's initial multi-host SDK timeout under concurrent QEMU work was retained and passed unchanged on isolated retest. Non-root Docker completed dictionary, task, report and recheck flows. Final documentation-only repacking changed seven Markdown files, with all executable/runtime/dependency bytes unchanged and exact archives re-audited. Original Core source stays private. Existing installations and the separate local workbench were not modified.
