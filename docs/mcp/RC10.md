## 简体中文

本版同步 B345 的字典管理、模型设置、生成指令和响应处理。**原生 Core 计算器算法未改**，不需要另装 58618，也不需要开发者提供模型服务器。

- **L2：8 个 JSON＋README；L3：3 个 JSON＋README。** [完整格式](npm/guides/DICTIONARIES.zh-CN.md) 与中英文目录示例随包提供，可通过 MCP 直接读取。
- 页面分为“已安装字典”和“导入语义库”，五步：选择层级 → 选择文件夹 → 校验 → 名称 → 保存。校验通过才可保存，名称和绑定刷新后保留。
- 模型设置与字典分别保存。API Key 掩码展示、留空保留；保存不触发模型请求。默认继续使用当前宿主 LLM。
- 同步任务边界与执行状态区分、形式输入条件要求、流式接收状态和数学 JSON 转义处理。原响应保留，不修改模型判定或计算操作数。
- rc.9 旧字典、任务、失败和历史报告保留。旧 JSON 工具导入仍兼容；管理安装采用复制迁移，已有连接不强制重启。

浏览器实际验证了中英文页面、L2/L3 完整目录导入、名称及绑定刷新保留、模型设置独立保存。原始 JavaScript/C++ Core、凭据及个人任务未进入产品包；适配层、UI、提示词和语义资源仍可读。未操作 58618。

## English

rc.10 incorporates B345 dictionary management, independent model settings, task-boundary instructions, streaming receipts and JSON math-escape handling. **The native calculator algorithm is unchanged.** L2 requires 8 JSON files plus README; L3 requires 3 JSON files plus README. Both MCP and UI share validation and storage, with complete bilingual examples. Existing rc.9 dictionaries and legacy JSON tool imports remain compatible.

The five-step UI validates a complete folder before naming and saving. Names and bindings persist after reload. Optional API model settings save independently; blank keys retain the saved key. The default current-host LLM workflow needs no extra API key. Saving settings does not submit analysis.

Windows and Linux each passed 682 calculation, 104 model-structure and 25 host-contract differential checks. Adapter suites each passed 58 tests with zero failures and five explicit historical-fixture skips. The final Windows archive passed installation/tamper tests and rc.9 migration/rollback preserving original configuration and 27 original files. Linux archive installation and Docker execution passed the full case/report/recheck flow.

A fresh host-LLM analysis of one parent and two DEV tasks produced four valid calculations. The final Windows/Linux/Docker packages replayed that same response, retaining the same report hash; this is clearly distinguished from new independent model analysis. No original Core source or customer history is included. Existing clients are not forcibly restarted. Historical Glama and directory approvals do not automatically apply to this new version.
