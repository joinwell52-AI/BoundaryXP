发布日期：2026-09-10。状态：私有预览分发，非正式产品 RELEASED。平台：Windows x64。

**[下载包与校验文件](https://github.com/joinwell52-AI/codeflowmu/releases/tag/boundx-v1.1.0-preview.1)** · [版本记录](../../CHANGELOG.md) · [首次使用](../../QUICKSTART.md)

## 本版解决什么问题

在原有边界差异检查上增加 PM 任务分解契约计算：即使每条原要求都有子任务关联，仍检查“子任务承诺的产出都成立，原交付是否可能缺失”。同时提供可直接解压运行的独立包，其他电脑不必下载整个 CodeFlowMu 源码。

## 相比源码 1.0.0 的变化

| 项目 | 本版变化 |
|---|---|
| 原要求追溯 | 找出未声明承担者的要求；关联不等于充分实现 |
| 完成条件 | 支持显式 all / any / not 与环境关系，返回两个方向的反例 |
| 子任务接口 | 检查上游产出是否足以保证下游输入 |
| 矛盾处理 | 环境、根要求、规划或上游矛盾单独提示，不作空真通过 |
| 调用入口 | 新增函数 reviewDecomposition、CLI decomposition、MCP bx_review_decomposition |
| 分发 | Windows x64 ZIP，内置 Node.js 24.16.0、LICENSE、示例与 CMD 启动脚本 |

数学原理、公式解释和 D044 案例详见 [任务分解计算手册](../DECOMPOSITION.md)。

## 限制与升级

最多 12 个布尔变量、4096 个状态；输入映射仍由调用方提供。引用存在不能证明语义正确，无反例不表示 PM 理解正确。不裁决、不自动派单或修复。

没有第二台物理电脑验收，没有真实 PM 自主纠正的新实验结论。没有图形界面和自动更新机制；新版本应解压到新目录，保留旧目录供回滚，宿主手动切换 MCP 路径。

本包不是 CodeFlowMu 安装包，不会自动注册到已安装的 CodeFlowMu。CodeFlowMu 携带、自动触发、版本固定及升级机制属于后续宿主开发。

本版本说明在首次分发后补充到仓库与 Release 页面；已发布 ZIP 未被覆盖，包内原有 QUICKSTART.md 和手册保持原样。本说明不应被误认为原 ZIP 已含此文件。
