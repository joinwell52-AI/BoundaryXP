# 1.2.0-preview.1 — 本地界面与模型入口

新增 `start-ui.cmd` / `npm run ui`：任务原文、可编辑七参数、基线确认、PM 规划与派单、差异与反例、回应、记录恢复及报告导出。

新增 Responses / Chat Completions 兼容调用。可以提取边界候选、生成 PM 拟议规划、带历史及提醒请求复核。模型选择原句编号，程序取回原文；编号错误拒绝，多片段引用覆盖范围明确提示。

服务仅绑定本机，校验 Host、Origin 和会话令牌；在线请求不跟随重定向，不自动重试。密钥不保存。无第三方运行依赖。

保留 CLI/MCP 及现有内核协议。产品版本为 1.2.0-preview.1，通用审阅协议版本仍是 1.0.0。CodeFlowMu 是否自动调用仍由其适配决定。

验证区分：真实豆包任务提取、PM 生成与最终规划提取均已完成，最后一次真实规划提取返回三份派单并进入内核计算；此前规划选择响应也完成了本地重放。前两次提取失败与规划格式失败均保留，不能宣传为一次无失败的全流程。31 项内核与界面服务测试通过。真实 PM 复核未另行收费运行，历史携带由本地测试覆盖；这不是语义准确率研究。

限制：首版界面中文；完整布尔分解编辑仍使用 CLI/MCP；页面不自动保存，关闭前请下载记录；未做全部供应商或第二台物理电脑验证。预览版本不代表 ADMIN 已批准正式 RELEASED。
