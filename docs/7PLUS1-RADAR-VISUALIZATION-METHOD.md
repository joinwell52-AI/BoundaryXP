# 7+1 雷达图形展示方法

## 单文本已有结果的条款—维度关联投影

| 项目 | 说明 |
|---|---|
| 方法标识 | `BX-RADAR-SINGLE-001` |
| 文档修订 | `0.2.1`，2026-10-16 |
| 图形投影版本 | `bxradar.single/0.2` |
| 参考中央图组件版本 | `bxradar.center/0.2.1` |
| 提出与维护 | BoundX 项目 |
| 定位 | 项目级图形展示方法与规范；不表示已获第三方认定的行业标准。 |
| 适用对象 | 已保存的单文本 7+1 结果，包括条款、维度归属、原文依据和已有数学分析。 |

> 本文说明“7+1结果如何生成图形”，不是“如何从自然语言生成7+1”。LLM已经生成的结果是展示输入；绘图程序只读这些结果，不再理解原文、不重新分类，也不以图形决定父子任务是否符合。

## 1. 方法解决什么问题

只有八个“已记录”状态的雷达不能说明任务规定了什么；另一方面，把时间、输入集合、参与者和禁止条件分别换成分数，也没有共同的数值尺度。

本方法保留雷达的八轴、轮廓和填充，建立两层相互引用的表达：

- **结构层**：一条边界关联哪些维度，用固定位置上的点、线、关联面表达。
- **内容层**：这条边界具体规定了什么，用已有结果正文、公式、条件、模态和原文依据表达。

两层共同组成标准展示。不得只交付没有内容的八边形，也不得用卡片或列表替代中央雷达。

```text
任务原文 → 既有LLM生成与审阅 → 已保存7+1结果
                                  │
                                  ├→ 只读适配 → 条款—维度投影 → 中央雷达
                                  │                           ↕ 选择事件
                                  │                       既有条款／证据区
                                  │
                                  └→ 原有父子比较逻辑 → 原有比较结果
```

新增图形没有回写上游或向比较器输入顶点、颜色、面积的路径。

## 2. 最小输入

一条已保存结果至少提供稳定任务身份、结果引用，以及各条款的 `id`、`text`、`axes`。原文引用、已有公式、审阅和问题记录在可用时原样带入，不要求为了画图增加模型请求。

```json
{
  "mode": "single",
  "task_id": "task-009",
  "result_ref": {"version": "v3"},
  "clauses": [
    {
      "id": "c4",
      "axes": ["A", "P", "R", "C"],
      "text": "若OPS在其env.json核查完成前确认高危，PM必须从该确认时点起0至10秒内完成暂停，两个端点均包含。暂停生效前，DEV和OPS的两项核查仍可执行；高危确认本身不立即禁止核查。"
    }
  ]
}
```

此处仅节选009中的一条，说明输入方式，不代表009完整结果只有一条。生产实现通过只读适配器使用现有字段，不要求迁移业务Schema。

`axes`必须来自已有结果。不得扫描条款关键词猜分类；即使对某项归属有语义异议，也应交给原有审阅流程，不能在前端静默改写。

## 3. 八轴坐标

从正上方开始顺时针固定排列，所有任务保持一致：

| 序号 k | 标识 | 图内名称 | 方向 |
|---:|---|---|---|
| 0 | I | 输入范围 | 上 |
| 1 | O | 产物交付 | 右上 |
| 2 | A | 动作关系 | 右 |
| 3 | P | 参与责任 | 右下 |
| 4 | R | 额度时间 | 下 |
| 5 | V | 版本依据 | 左下 |
| 6 | C | 完成与停止 | 左 |
| 7 | +1 B | 禁止限制 | 左上 |

B保留负向限制层含义，不是第八个正向评分。轴标题是展示名称，不能改变上游7+1定义。

设中心为 `(cx,cy)`、参考半径为 `R>0`，屏幕坐标的y轴向下：

```text
θk = −π/2 + k·π/4
pk = (cx + R·cosθk, cy + R·sinθk)
```

所有条款顶点位于同一个参考半径。半径不编码数量、时间、约束强度、风险、完整率或授权大小。背景八边形称为**八轴参考框**，不是“完整边界”“100%边界”或单文本的“父基线”。

## 4. 条款如何变成点、线和面

对一条边界c，取它已有的有效维度集合D(c)，按固定轴序排序，得到顶点序列H(c)：

```text
D(c) = c.axes在派生视图中的去重集合
H(c) = [pk | 第k轴属于D(c)，按k升序]
```

| 有效维度数 | 图形原语 | 解释 |
|---:|---|---|
| 1 | 一个关联点 | 该条款关联这一维度。 |
| 2 | 两点之间的一条无向线 | 两个维度同属一条款；不添加中心点。 |
| 3—8 | 按轴序连接、闭合并浅填充的关联面 | 这些维度共同描述这一条边界。 |

线无箭头，不代表先后、因果、数据流、许可或两两蕴含。一个关联面的相邻边不表示相邻两维之间另有独立命题。关联面不是任务解空间。

单轴、双轴条款不强造填充面；参考框仍保留。所有原条款身份和正文保留，几何结构只作为其视图。

### 4.1 同形条款与稳定排序

相同维度集合产生相同形状，这是预期行为。可用如下键将同形条款分组：

```text
mask(c) = Σ 2^k，求和范围为第k轴属于D(c)
```

mask只用于分组和测试，不作为业务数值显示。同形组必须保存全部 `clause_ids`，不能合并条款正文或删掉义务。常见c1、c2、c10按数字稳定排序；其他身份使用明确、稳定的代码点排序，不依赖浏览器默认语言。

改变条款正文中的20分钟为2分钟，但axes不变时，形状不变；文字、公式及来源版本应变化。不能为了让不同任务“长得不同”而随机抖动角度或拉伸半径。

### 4.2 无效输入

axes缺失、为空或包含未知轴时，该条款进入“未映射条款”，保留正文和原因；不能丢掉坏轴后画出貌似完整的轮廓。重复条款ID阻止该结果的正式投影，不覆盖旧条款。同条款axes内部重复可在派生视图去重，但必须保留诊断。

没有收到条款列表不等于空列表；没有已映射条款不等于“原文没有边界”。展示层不能据空数组补出“未明示”“不适用”或“已验证”。

## 5. 同一张图的三个状态

| 状态 | 中央图形 | 与既有详情区的联动 |
|---|---|---|
| 任务总览 | 八轴参考框、低对比轮廓簇、浅填充、各轴内容和总条款数 | 保留宿主已有总览行为。 |
| 维度聚焦 | 固定八轴不动，突出所选维度关联的条款 | 调用原有选择处理器列出该维条款。 |
| 条款聚焦 | 中心明确标出条款ID，突出其全部关联节点及点／线／面 | 展示同一条款全文、已有公式和原文证据。 |

总览按稳定结构组绘制，相同边可去重描画，但组与条款的归属必须完整保存。透明叠色只为层次，不代表风险或强度。条款较多时允许图内分组显示，但必须说明当前显示范围；不能改变全任务条款数。

点击重叠区域不能任意选中最后绘制的条款，应返回候选 `clause_ids` 给宿主选择。点击图内中心或在图内按Escape返回总览。不得安装影响整页的快捷键。

## 6. 内容、公式与证据

每轴标注包含：**维度标题、有关的已有内容节选、关联条款数量及引用**。不能只重复“已记录”。

内容优先读取已有且绑定条款的摘要或公式；没有时稳定选取原条款节选，标明“节选，完整条件见条款”。人工显示注释可单独保存并标来源，但不能写回7+1或成为比较输入；完成绘图不以增加注释字段为前提。

条款聚焦时，关联轴的标注必须来自焦点条款或明确关联的既有分析。例如009/c4的R标注对应0—10秒暂停窗口，不能换成c11的30分钟总耗时。

不得为了短文案删去“仅在”“必须”“可以”“不含首次”“不自动恢复”或区间端点后，冒充完整规则。已有数学分析必须保留来源类型；“LLM分析”不能被展示成“程序证明”。审阅未发现问题也不构成数学证明或执行授权。

所有条款、公式和证据引用绑定同一保存版本。中文原文定位须明确UTF-8字节、Unicode码点或UTF-16码元坐标；高亮前检查引文一致性，不能混用偏移。

## 7. 图形设计约定

| 图形元素 | 含义与默认显示 |
|---|---|
| 浅灰蓝细虚线参考框 | 固定类别坐标，无数值刻度。 |
| 蓝色低对比轮廓与浅填充 | 已有条款的关联结构。 |
| 青色较粗轮廓、浅青填充和高亮节点 | 用户当前选中的条款，不表示已获批准。 |
| 暖色“+1 B”标签 | 禁止限制这一维度，不表示错误或高风险。 |
| 空心类别节点及文字 | 没有已映射条款；仅陈述展示事实。 |
| 独立问题徽标 | 只显示上游明确给出的未决、冲突或来源问题。 |

可沿用参考组件的主轮廓色 `#3569D4`、焦点色 `#078C9F`、B标签色 `#A76416`；焦点线宽2.4、填充不透明度0.14是参考值。颜色和像素值可以适应现有主题，图形含义和八轴顺序不能随任务改变。颜色应配合文字或形状，而不是唯一识别方式。

本次工程范围只包括58618已有的**中央绘图区**。顶栏、宣传标题、左右栏、按钮、日志、历史及整页布局不重做。中央图通过原有事件更新已有详情；不能为适应新图先重排整个工作台。

## 8. 示例：同一方法的点、线和面

下列对应关系来自已有002、009保存报告，不是重新调用模型生成的结果。

| 示例 | 已有axes | 预期图形 | 内容摘要 |
|---|---|---|---|
| 002/c9 | R | 单点 | 0＜总耗时≤20分钟。 |
| 002/c3 | I/B | 无向线 | c.csv禁读，可读输入为a.csv、b.csv；三个输入均禁改。 |
| 009/c4 | A/P/R/C | 四顶点关联面 | 指定高危确认条件成立时，PM须在0—10秒内完成暂停，含两端。 |

### 8.1 c4的投影展开

选中009/c4时，中心显示“c4 · 条款聚焦”，高亮A/P/R/C四个节点，按轴序连接并浅填充。其余结构弱化，不能把这张聚焦图标成完整任务总览。

c4对应的四个单位坐标依次为：

```text
A = (1, 0)
P = (√2/2, √2/2)
R = (0, 1)
C = (−1, 0)
```

其原有数学分析为：

```text
满足c4触发条件时，0秒 ≤ t_暂停完成 − t_高危确认 ≤ 10秒
来源：LLM分析（非程序证明）
```

几何表达四维共同归属；触发条件、必要义务、暂停生效时点和区间端点仍由条款正文与公式表达。连线不表示四个动作的执行顺序。

### 8.2 可复核的结构计数

| 保存样例 | 唯一条款数 | 同形结构组数 | 全部维度关联次数 |
|---|---:|---:|---:|
| 002 | 10 | 9 | 29 |
| 009 | 12 | 11 | 44 |

009/c7和c10同属O/A/P/C，但分别规定高危汇报和报告交付，不能因同形合并成同一义务。全任务条款数按唯一ID计算，不等于八轴关联次数之和。以上是固定样例的显示校验，不是一般任务的固定参数。

## 9. 工程实现与一致性要求

```text
adaptSavedSingleResult()       只读适配已有结果
  → buildSingleRadarProjection()  固定轴序、分组、坐标和内容引用
  → renderCentralRadar()          只操作传入的中央SVG或绘图容器
  → existingSelectionHandler()    复用现有条款与证据联动
```

函数名仅说明职责，不要求重写架构或替换整个workbench文件。相同保存结果和投影版本必须得到相同结构；重排输入数组不应改变几何分组，允许明确的数值舍入误差，不要求不同设备抗锯齿像素完全相同。

绘图、焦点切换、历史回看和展示导出新增模型请求为0。缓存绑定结果身份、版本／摘要、投影版本和适配器版本。导出须注明任务／结果引用、规范版本、当前焦点及是否过滤；展示快照不是业务证书。

组件的DOM、CSS和事件限定在中央容器，不修改body、全局按钮／SVG样式或父子页面。卸载不留监听，旧版本结果迟到时不能覆盖当前结果。输入中的命令、HTML和公式仅作为数据安全显示，不执行脚本，不使用eval。

### 9.1 最低一致性检查

| 检查 | 要求 |
|---|---|
| 固定轴与原语 | 轴序正确，点／线不补中心点，多维面不增加未关联轴。 |
| 同形与顺序 | 不丢条款身份，重排输入不改变几何分组。 |
| 内容变化 | 同axes不同数值可同形，但标注、正文和版本准确对应。 |
| 三种状态 | 总览、维度、条款焦点有明确标识，图文引用一致。 |
| 无效／空态 | 缺失列表、空列表、无效axes、重复ID分别处理。 |
| 来源与安全 | 条件与端点不丢失，LLM与程序依据不混淆，中文引文定位准确。 |
| 宿主隔离 | 同状态前后对比，中央图以外UI保持原样；数据与历史摘要不变。 |
| 父子非回归 | 固定输入下既有比较的业务字段、发现项、预算、未决和版本不变。 |

001—010应用回归只读取本地已有结果，缺失样本标记未运行，不调用模型补齐。参考投影测试、宿主UI测试、父子比较回归和实际部署必须分别记录，不能用参考截图冒充本机验收。

## 10. 方法的适用边界

本图**不是完整语义的可逆编码**：相同形状不代表同一条款、同一授权或语义等价；不同形状也不自行构成冲突。形状包含、重叠、面积和相似度都不能证明父子符合、覆盖、可行性或执行完成。

本方法标准化的是“已给定条款—维度归属的可重复表达”，不保证上游LLM理解正确，也不把数学分析显示成已被程序证明。不得添加无依据的完整率、复杂度分级或风险分数。
